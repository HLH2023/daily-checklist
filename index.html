▶🧩 LeetCode 每日一题：Find X Value of Array IIHard
给定正整数数组 nums、正整数 k，以及查询 [index, value, start, x]。每次查询先把 nums[index] 更新为 value（更新会保留），再删除 nums[0..start-1]，然后可以删除剩余数组的任意后缀，但数组必须非空。x-value 是保留下来的非空前缀的乘积对 k 取模等于 x 的方案数；返回每个查询的答案。
💡 解题思路：每个查询实际上是在动态数组区间 nums[start..n-1] 中，统计所有非空前缀的乘积模 k 等于 x 的个数。由于 k≤5，可在线段树每个节点保存：整个区间乘积模 k，以及该区间所有非空前缀乘积模 k 的计数数组。合并左右节点时，左区间的前缀直接保留，右区间前缀要乘上左区间的总乘积；点更新后重新合并路径，区间查询用两个累加器保持左右顺序。
🔧 题解：节点合并：prod=(left.prod*right.prod)%k；cnt 先累加 left.cnt，再把 right.cnt 按 left.prod 循环移位后累加。用长度为 2n 的迭代线段树支持 O(log n·k) 的单点更新和后缀查询，总复杂度 O((n+q)log n·k)，空间 O(nk)。
from typing import List

class Solution:
    def resultArray(self, nums: List[int], k: int, queries: List[List[int]]) -> List[int]:
        n = len(nums)
        identity = 1 % k

        def merge(left, right):
            lp, lc = left
            rp, rc = right
            cnt = lc[:]
            for r, amount in enumerate(rc):
                cnt[(lp * r) % k] += amount
            return ((lp * rp) % k, cnt)

        def leaf(value):
            residue = value % k
            cnt = [0] * k
            cnt[residue] = 1
            return (residue, cnt)

        empty = (identity, [0] * k)
        size = 1
        while size < n:
            size <<= 1
        tree = [empty] * (2 * size)
        for i, value in enumerate(nums):
            tree[size + i] = leaf(value)
        for i in range(size - 1, 0, -1):
            tree[i] = merge(tree[i << 1], tree[i << 1 | 1])

        def update(pos, value):
            p = size + pos
            tree[p] = leaf(value)
            p >>= 1
            while p:
                tree[p] = merge(tree[p << 1], tree[p << 1 | 1])
                p >>= 1

        def query(left, right):
            left_acc = empty
            right_acc = empty
            l, r = left + size, right + size
            while l < r:
                if l & 1:
                    left_acc = merge(left_acc, tree[l])
                    l += 1
                if r & 1:
                    r -= 1
                    right_acc = merge(tree[r], right_acc)
                l >>= 1
                r >>= 1
            return merge(left_acc, right_acc)

        answer = []
        for index, value, start, x in queries:
            update(index, value)
            answer.append(query(start, n)[1][x])
        return answer

A. cwnd=10 MSS，ssthresh=10 MSS
B. cwnd=13 MSS，ssthresh=10 MSS
C. cwnd=20 MSS，ssthresh=13 MSS
D. cwnd=23 MSS，ssthresh=20 MSS
答案：A
📖 解析：3 个重复 ACK 时，ssthresh=cwnd/2=10 MSS，并临时将 cwnd=ssthresh+3=13 MSS。快恢复结束、收到新 ACK 后，Reno 将 cwnd 降回 ssthresh，因此最终 cwnd=10 MSS、ssthresh=10 MSS。

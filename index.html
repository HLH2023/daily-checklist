▶🧩 LeetCode 每日一题：Lexicographically Smallest Permutation Greater Than TargetMedium
给定两个长度均为 n、只含小写英文字母的字符串 s 和 target。请返回 s 的所有排列中字典序严格大于 target 的最小排列；如果不存在这样的排列，返回空字符串。对于等长字符串，字典序比较看第一个不同位置，字母更靠后的字符串更大。
💡 解题思路：枚举答案与 target 最后一个不同的位置 i，并让前缀 target[:i] 完全保留。为了让结果尽可能小，应优先尝试最靠右的 i：在剩余字符中选一个严格大于 target[i] 的最小字符作为转折点，再把剩余字符按升序排列。若 target[:i] 无法由 s 的字符组成，跳过该位置；从右向左第一个可行位置就是答案。
🔧 题解：用字符频次表表示 s。对 i 从 n-1 递减到 0，重新复制频次表并尝试消耗 target[:i]；若前缀可行，则在剩余字符中寻找大于 target[i] 的最小字符。选定后将其消耗，并把所有剩余字符升序拼接。右移转折点能保留更长的 target 前缀，因此得到字典序更小的可行结果。若所有位置都失败，返回空串。时间复杂度 O(n²+26n)，空间复杂度 O(n)。
from collections import Counter

class Solution:
    def lexicographicallySmallestPermutation(self, s: str, target: str) -> str:
        n = len(s)
        for i in range(n - 1, -1, -1):
            count = Counter(s)
            possible = True
            for ch in target[:i]:
                if count[ch] == 0:
                    possible = False
                    break
                count[ch] -= 1
            if not possible:
                continue

            greater = next(
                (ch for ch in sorted(count)
                 if ch > target[i] and count[ch] > 0),
                None,
            )
            if greater is None:
                continue
            count[greater] -= 1
            suffix = ''.join(ch * count[ch] for ch in sorted(count))
            return target[:i] + greater + suffix
        return ""

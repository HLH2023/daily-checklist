▶🧩 LeetCode 每日一题：Check Divisibility by Digit Sum and ProductEasy
给定一个正整数 n，计算 n 的数位和与数位积之和；如果 n 能被这个和整除，返回 true，否则返回 false。例如 n=99 时，数位和为18、数位积为81，二者之和为99，因此返回 true。
💡 解题思路：逐位拆分 n，同时累加数位和、累乘数位积。遍历结束后得到 divisor=sum+product，最后判断 n%divisor 是否为 0。题目判断的是‘数位和与数位积之和’，不是分别判断 n 是否能被二者整除。
🔧 题解：用取模 10 得到当前最低位，再用整除 10 删除该位；初始 product 设为 1。n≤10^6，最多处理 7 位数字，时间复杂度 O(log n)，额外空间复杂度 O(1)。
class Solution:
    def checkDivisibility(self, n):
        x = n
        digit_sum = 0
        digit_product = 1

        while x > 0:
            digit = x % 10
            digit_sum += digit
            digit_product *= digit
            x //= 10

        return n % (digit_sum + digit_product) == 0

▶📐 线代·向量：线性相关性常用结论线代·向量
相关组加向量仍相关；无关组部分仍无关；延伸保持无关；s>t时s个向量由t个表示必相关
📌 要点：线性相关与线性无关的判定可以通过删去、添加向量以及向量个数与生成空间维数的关系快速完成。n 维空间中任意 n+1 个向量必相关；无关组的任意部分仍无关，而向量组相关时再添加向量不会变为无关。
• 相关组添加任意向量仍相关，无关组取任意部分仍无关
• 无关组中添加一个不能由原组表示的向量后仍可保持无关
• s>t 时 s 个向量若都由 t 个向量线性表示，则这 s 个向量必相关

🧭 套路：判定时关注‘添加’还是‘取部分’以及向量个数与空间维数；不要把相关组删去向量后的结论误认为仍必相关。
▶📐 线代·向量：极大线性无关组线代·向量
秩=极大无关组向量个数
📌 要点：极大线性无关组既要满足组内线性无关，又要能表示原向量组中的每个向量；等价地，再向其中加入原组中的任一向量都会线性相关。极大无关组中向量的个数就是向量组的秩。
• 极大无关组是原向量组的子组，组内必须线性无关
• 原向量组中的每个向量都能由极大无关组线性表示
• 同一向量组的不同极大无关组所含向量个数相同，均等于秩
默写核心结论：＿＿＿
秩=极大无关组向量个数
🧭 套路：把向量组排成矩阵并化为阶梯形，主元列对应的一组原向量可作为极大无关组；秩为主元个数。

A. 输出 3、2、1；调用阶段先处理 f(3)
B. 输出 1、2、3；调用阶段先到达 f(3)，返回阶段先处理 f(1)
C. 输出 1、2、3；调用阶段先到达 f(1)，返回阶段先处理 f(3)
D. 输出 3、2、1；调用阶段先到达 f(1)，返回阶段先处理 f(3)
答案：B
📖 解析：调用 f(3) 后依次压入 f(3)、f(2)、f(1)，到达递归基后开始退栈；输出语句在递归调用返回之后，所以退栈顺序为 f(1)、f(2)、f(3)，输出 1、2、3。递归调用阶段最后到达 f(1)，但最先处理的栈帧是栈顶的 f(1)。

▶关于用户级线程和内核级线程，下列说法正确的是（ ）操作系统简单
A. 用户级线程的线程切换必须由内核完成
B. 用户级线程库可以在用户态完成线程切换，但一个线程阻塞可能使同一进程的其他用户线程也无法运行
C. 内核级线程不需要内核保存寄存器和程序计数器
D. 用户级线程和内核级线程都一定拥有独立的进程地址空间
答案：B
📖 解析：用户级线程由线程库管理，切换可在用户态完成，开销较小；但若内核只把进程视为调度单位，进程内一个用户线程阻塞可能导致整个进程阻塞。内核级线程由内核感知并调度，内核需要保存其执行现场；线程共享所属进程的地址空间。
▶采用 3 bit 编号字段的滑动窗口协议，在不限制接收方窗口的条件下，为避免序号空间歧义，后退 N 帧（GBN）和选择重传（SR）的发送窗口最大值分别应为（ ）计算机网络中等
A. GBN 为 4，SR 为 4
B. GBN 为 7，SR 为 4
C. GBN 为 8，SR 为 4
D. GBN 为 7，SR 为 7
答案：B
📖 解析：序号空间大小 N=2³=8。GBN 的接收窗口为1，发送窗口最大为 N−1=7；SR 的发送窗口和接收窗口都不能超过序号空间的一半，最大为 N/2=4，否则旧帧与新帧可能无法区分。因此选 B。
▶关于多线程模型，下列说法中正确的是（ ）操作系统困难
A. 多对一模型把多个用户级线程映射到多个内核级线程，因此可在多核上并行
B. 一对一模型中一个用户线程对应一个内核线程，能提供较好的并发性，但创建和管理线程的内核开销较大
C. 多对多模型要求用户级线程数必须等于内核级线程数，否则无法进行映射
D. 多对一模型中某个用户线程执行阻塞系统调用时，内核会自动改调度同一进程中的其他用户级线程
答案：B
📖 解析：一对一模型为每个用户线程建立一个内核线程，内核可以独立调度，阻塞一个线程通常不妨碍同进程其他线程运行，但内核线程数量增多会带来创建、调度和切换开销。多对一实际是多个用户线程映射到一个内核线程，不能利用多核且一个阻塞调用可能阻塞全部线程；多对多不要求两者数量相等，而是把多个用户线程多路复用到不超过其数量的内核线程上。

▶🧩 LeetCode 每日一题：Maximum Nesting Depth of Two Valid Parentheses StringsMedium
给定一个合法括号字符串 seq，将其中每个字符分配给组 A 或组 B（返回由 0 和 1 组成的数组），使两组各自形成合法括号字符串，并让两组中较大的最大嵌套深度尽可能小。括号匹配关系不能改变。
💡 解题思路：从左到右维护原串当前嵌套深度。把每一对括号按其所在层的奇偶性分配：进入左括号后深度加一，将它分到 depth%2 组；右括号在深度尚未减一时分到同一层奇偶组，再将深度减一。奇偶层交替分配后，每组内部的括号仍然匹配，且原最大深度 D 被均分到两组，最深不超过 ceil(D/2)。
🔧 题解：每个字符只处理一次，时间复杂度 O(n)，额外空间 O(n)（返回数组）。
from typing import List

class Solution:
    def maxDepthAfterSplit(self, seq: str) -> List[int]:
        ans = []
        depth = 0
        for ch in seq:
            if ch == '(':
                depth += 1
                ans.append(depth % 2)
            else:
                ans.append(depth % 2)
                depth -= 1
        return ans

B. inode 保存文件属性及数据块索引，目录项将文件名映射到 inode

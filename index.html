▶🧩 LeetCode 每日一题：Construct Uniform Parity Array II中等
给定一个由 n 个互不相同的正整数组成的数组 nums1，需要构造长度同为 n 的 nums2，使其元素全部为奇数或全部为偶数。对每个下标 i，必须任选一种操作：令 nums2[i]=nums1[i]，或选择 j≠i 且 nums1[i]-nums1[j]≥1，令 nums2[i]=nums1[i]-nums1[j]。判断是否能够构造出满足条件的 nums2。例：[1,4,7] 可构造为 [1,3,7]，答案为 true；[2,3] 无法统一奇偶性，答案为 false。
💡 解题思路：分别考虑目标为全奇数和全偶数。若数组最小值为奇数，可以把它作为减数：所有偶数减去这个更小的奇数后变成奇数，原本的奇数直接保留，因此可行。若数组中全为偶数，全部直接保留即可。反之，若最小值为偶数且数组中存在奇数，最小的奇数没有更小的奇数可供相减，不能变成偶数；它也不是偶数，所以不可能统一。
🔧 题解：设 mn=min(nums1)。目标为全奇数时，mn 为奇数即可：奇数元素保留，偶数元素减去 mn。目标为全偶数时，只有数组全为偶数才可行；若存在奇数，取最小的奇数，它没有更小的奇数可减，无法变成偶数。因此答案为 mn 为奇数，或所有元素均为偶数。只需一次扫描求最小值并检查是否全偶数，时间复杂度 O(n)，额外空间复杂度 O(1)。
from typing import List

class Solution:
    def uniformArray(self, nums1: List[int]) -> bool:
        mn = min(nums1)
        # mn 为奇数时可统一为奇数；全偶数时直接保留即可。
        return mn % 2 == 1 or all(x % 2 == 0 for x in nums1)

▶多个生产者和多个消费者共享大小为 N 的有界缓冲区，信号量 empty、full、mutex 的初值分别为 N、0、1。一个生产者放入一个产品时，正确的 P/V 操作顺序是：操作系统简单
A. P(mutex)，P(empty)，放入产品，V(full)，V(mutex)
B. P(empty)，P(mutex)，放入产品，V(mutex)，V(full)
C. P(full)，P(mutex)，放入产品，V(mutex)，V(empty)
D. P(empty)，V(mutex)，放入产品，P(mutex)，V(full)
答案：B
📖 解析：生产者先执行 P(empty) 申请空槽；再执行 P(mutex) 进入临界区，完成写入；离开临界区时先 V(mutex) 释放互斥锁，再 V(full) 使满槽数加一。若先 P(mutex) 再等待 empty，缓冲区满时生产者会持锁阻塞，消费者可能无法获得锁取出产品而产生死锁。

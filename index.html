▶🧩 LeetCode 每日一题：Smallest Index With Digit Sum Equal to IndexEasy
给定整数数组 nums，返回最小下标 i，使 nums[i] 的各位数字之和等于 i；若不存在这样的下标，返回 -1。
💡 解题思路：从左到右枚举下标，逐位累加 nums[i] 的十进制数字和。由于要求最小下标，首次满足条件即可返回；遍历结束仍未命中则返回 -1。
🔧 题解：对每个非负整数 x，反复取 x % 10 累加数字和，并令 x //= 10。将数字和与当前下标比较。每个元素最多处理其位数，数组长度为 n、元素最大值为 M 时，时间复杂度 O(n log M)，额外空间 O(1)。
from typing import List

class Solution:
    def smallestIndex(self, nums: List[int]) -> int:
        for i, value in enumerate(nums):
            x = value
            digit_sum = 0
            while x > 0:
                digit_sum += x % 10
                x //= 10
            if digit_sum == i:
                return i
        return -1

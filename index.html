▶🧩 LeetCode 每日一题：Find the Largest Almost Missing IntegerEasy
给定整数数组 nums 和整数 k。如果整数 x 出现在长度为 k 的连续子数组中恰好一次，则称 x 为 almost missing。返回最大的 almost missing 整数；如果不存在则返回 -1。
💡 解题思路：枚举 nums 的每个长度为 k 的窗口，用集合去重后统计每个整数出现于多少个窗口。最后在计数恰好为 1 的元素中取最大值。窗口数量最多为 n，因此直接遍历窗口并更新计数即可。
🔧 题解：遍历所有起点 i=0..n-k，令 window=set(nums[i:i+k])，其中每个元素只对当前窗口计数一次。完成统计后遍历计数表，返回 count[x]==1 的最大 x；若没有符合条件的元素返回 -1。时间复杂度 O(nk)，空间复杂度 O(n)。
from collections import Counter

class Solution:
    def largestAlmostMissingInteger(self, nums, k):
        appeared = Counter()
        for i in range(len(nums) - k + 1):
            for x in set(nums[i:i + k]):
                appeared[x] += 1
        candidates = [x for x, count in appeared.items() if count == 1]
        return max(candidates, default=-1)

▶两个递增单链表 L1=(1,4,7) 和 L2=(2,3,8,9) 合并为一个递增单链表。若采用带头结点的就地归并，最终结点序列及时间复杂度分别是（ ）数据结构困难
A. 1→2→3→4→7→8→9，O(m+n)
B. 1→4→7→2→3→8→9，O(mn)
C. 2→3→8→9→1→4→7，O(m+n)
D. 1→2→4→3→7→8→9，O(m+n)
答案：A
📖 解析：归并时比较两个表当前结点，较小者摘下并接到结果链表尾部：依次取 1、2、3、4、7，L1 用尽后把 L2 剩余的 8、9 接到尾部，因此结果为 1→2→3→4→7→8→9。每个结点最多被比较、摘接一次，故时间复杂度为 O(m+n)，只使用若干指针，辅助空间为 O(1)。
▶设机器字长为 8 位，采用偏置值为 128 的移码表示。若某数的真值为 -5，则其移码（按 8 位无符号位模式写出）为（ ）计算机组成原理中等
A. 0111 1011B
B. 1000 0101B
C. 1111 1011B
D. 0111 1111B
答案：A
📖 解析：移码通常按 [x]移=x+2^(n-1) 计算，8 位时偏置值为 128。真值 -5 的移码数值为 -5+128=123，123 的 8 位二进制为 0111 1011B，因此选 A。移码的符号位与补码相反，常用于浮点数阶码比较大小。
▶关于进程与程序的区别，下列说法正确的是（ ）操作系统简单
A. 程序是动态执行的，进程是静态的指令集合
B. 一个程序只能对应一个进程，不能同时产生多个进程
C. 进程是程序的一次执行过程，具有动态性；PCB 是进程存在的唯一标志
D. 进程只包含程序代码，不包含运行时的状态和资源信息
答案：C
📖 解析：程序是静态的代码和数据集合，进程是程序的一次执行过程，具有动态性、并发性和独立性。同一个程序可以对应多个进程，例如多个用户同时运行同一程序。PCB 记录进程状态、程序计数器、寄存器、资源等信息，是进程存在的唯一标志；进程并不只包含代码。
▶关于电路交换、报文交换和分组交换，下列说法正确的是（ ）计算机网络简单
A. 电路交换在通信双方传输数据前建立一条专用物理通路，传输期间通常独占相关资源
B. 报文交换要求通信双方先建立固定的端到端电路，且报文不能存储转发
C. 分组交换把报文整体作为一个不可分割的数据单元转发，不需要排队等待
D. 三种交换方式都不需要节点缓存，因此都不会产生排队时延
答案：A
📖 解析：电路交换需要先建立连接，通信期间独占所建立的通路，适合连续、稳定的传输。报文交换以完整报文为单位采用存储转发，不预先建立专用电路；分组交换把报文拆成较小分组，逐个存储转发，可能产生排队时延。故 B、C、D 均错误。
▶在采用共享存储的进程通信中，下列说法正确的是（ ）操作系统简单
A. 共享内存区只能由一个进程访问，其他进程只能通过消息读取
B. 共享存储允许多个进程直接读写同一物理内存区域，但对共享数据的并发访问仍需同步互斥
C. 共享存储天然保证多个进程对同一变量的读写具有原子性
D. 共享存储不需要操作系统建立或映射共享区域，进程可访问任意物理地址
答案：B
📖 解析：共享存储由操作系统建立或映射一块可被多个进程访问的共享区域，进程可直接读写该区域，通信速度较快。但多个进程并发访问共享数据会产生竞态条件，仍需信号量、互斥锁等同步机制；共享存储不保证任意读写操作的原子性，也不允许进程随意访问物理地址。

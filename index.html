▶🧩 LeetCode 每日一题：Longest Subsequence With Non-Zero Bitwise XORMedium
给定整数数组 nums，返回最长的「子序列」长度，使得该子序列中所有元素的按位异或（XOR）结果不为 0。若不存在这样的子序列，返回 0。
💡 解题思路：设 total 为整个数组的异或和。若 total ≠ 0，则整个数组本身就是一个合法子序列，答案就是 n。若 total == 0，说明需要删掉至少一个元素：删掉元素 x 后，剩余元素的异或 = total ^ x = x，因此只要存在非零元素，删掉它即可让剩余异或非零，答案 n-1。若数组全为 0，任何子序列异或都为 0，答案 0。
🔧 题解：先求全局异或 total。total != 0 → 返回 n；total == 0 且存在非零元素 → 返回 n-1；全零数组 → 返回 0。核心性质：a ^ a = 0，且 total ^ x 恰好等于删去 x 后剩余元素的异或。
class Solution:
    def longestSubsequence(self, nums: List[int]) -> int:
        total = 0
        for x in nums:
            total ^= x
        if total != 0:
            return len(nums)
        return len(nums) - 1 if any(nums) else 0

▶📐 线代·行列式与矩阵：初等矩阵线代
E(i,j)、E(i(k))、E(ij(k))；|E(i,j)|=−1，|E(i(k))|=k，|E(ij(k))|=1
📌 要点：单位矩阵 E 经一次初等变换得到的矩阵称为初等矩阵，共三种类型。
• E(i,j)：交换 i、j 两行(列)，行列式 = −1
• E(i(k))：第 i 行(列)乘 k，行列式 = k
• E(ij(k))：第 j 行乘 k 加到第 i 行，行列式 = 1
• 左乘行变换、右乘列变换；初等矩阵的逆仍是同类型初等矩阵
默写核心结论：＿＿＿
E(i,j)、E(i(k))、E(ij(k))；|E(i,j)|=-1,|E(i(k))|=k,|E(ij(k))|=1
🧭 套路：初等矩阵都可逆：E(i,j)⁻¹ = E(i,j)，E(i(k))⁻¹ = E(i(1/k))，E(ij(k))⁻¹ = E(ij(−k))。

▶长度为 n（n≥2）的顺序表，在表中第 i（1≤i≤n+1）个位置插入一个新元素需移动____个元素；删除第 i（1≤i≤n）个位置上的元素需移动____个元素。数据结构简单
A. n-i；n-i+1
B. n-i+1；n-i
C. n-i；n-i
D. n-i+1；n-i+1
答案：B
📖 解析：插入时，第 i 个位置及其后的所有元素（共 n-i+1 个）都要后移；删除时，第 i 个位置之后的元素（共 n-i 个）前移。平均移动次数：插入约为 n/2，删除约为 (n-1)/2，均属 O(n)。
▶某程序的可并行部分占 75%，其余为串行部分。采用 8 个处理器并行执行可并行部分，则整体加速比约为____。计算机组成原理困难
A. 2.29
B. 2.67
C. 2.91
D. 3.33
答案：C
📖 解析：Amdahl 定律：S = 1 / [(1-f) + f/p]，其中 f=75%=0.75 为可并行比例，p=8。S = 1 / [0.25 + 0.75/8] = 1 / [0.25 + 0.09375] = 1/0.34375 ≈ 2.91。注意串行部分比例(1-f)是加速比的上限瓶颈，无论 p 多大，S 最大不超过 1/(1-f)=4。
▶关于进程的特征，下列说法错误的是____。操作系统简单
A. 动态性是进程最基本的特征
B. 并发性指多个进程在任意时刻都可以同时运行
C. 独立性指进程是独立获得资源和独立调度的基本单位
D. 异步性指进程按各自独立的、不可预知的速度推进
答案：B
📖 解析：并发性指多个进程在同一时间间隔内同时推进（宏观上同时、微观上交替），而非『任意时刻同时运行』——那是对『并行』的描述。A、C、D 分别是进程的动态性、独立性、异步性的标准表述，均正确。
▶某有噪声信道带宽为 3 kHz，信噪比 S/N = 1023（即 30 dB）。根据香农定理，该信道的最大数据传输速率约为____。计算机网络中等
A. 10 kbps
B. 20 kbps
C. 30 kbps
D. 40 kbps
答案：C
📖 解析：香农公式：C = W·log₂(1 + S/N) = 3000 × log₂(1 + 1023) = 3000 × log₂1024 = 3000 × 10 = 30000 bps = 30 kbps。注意信噪比直接给的是比值 S/N=1023（30 dB 只是分贝表示，log₂(1024)=10），计算时直接用比值即可。
▶关于曼彻斯特编码与差分曼彻斯特编码，下列说法正确的是____。计算机网络简单
A. 曼彻斯特编码每个比特中间有跳变，跳变仅用于同步，不携带数据
B. 曼彻斯特编码每个比特中间有跳变，既表示数据又提供时钟同步，属于自含时钟编码
C. 曼彻斯特编码通过有无跳变来区分 0 和 1
D. 差分曼彻斯特编码每个比特中间必须发生跳变，且跳变本身表示数据
答案：B
📖 解析：曼彻斯特编码：每个比特中间必有一次跳变，跳变既作为时钟信号又表示数据（如高→低表示 1，低→高表示 0），自含时钟，故 A 错、B 对。差分曼彻斯特编码：中间跳变仅用于同步，用『比特开始处有无跳变』表示 0/1，故 C、D 错。

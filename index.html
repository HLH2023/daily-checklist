▶🧩 LeetCode 每日一题：Count Commas in Range II中等
给定整数 n，返回按标准数字格式书写 1 到 n（含 n）时使用的逗号总数。标准格式从右侧起每三位数字插入一个逗号，少于 4 位的数字不含逗号。约束：1 ≤ n ≤ 10^15。
💡 解题思路：按逗号数量分组统计：1000～999999 的每个数含 1 个逗号，1000000～999999999 的每个数含 2 个逗号，依此类推。对第 k 组计算区间与 [1,n] 的交集大小，再乘以 k 并累加，避免逐个格式化数字。
🔧 题解：设当前组起点为 10^(3k)，终点为 10^(3k+3)-1；若 n 覆盖该组，就把 (min(n,终点)-起点+1)×k 加入答案，然后起点乘 1000、逗号数加 1。n ≤ 10^15，循环次数很少，时间复杂度 O(log n)，空间复杂度 O(1)。
class Solution:
    def countCommas(self, n: int) -> int:
        ans = 0
        start = 1000
        commas = 1
        while start <= n:
            end = min(n, start * 1000 - 1)
            ans += (end - start + 1) * commas
            start *= 1000
            commas += 1
        return ans

▶对权值为 2、3、7、9、12 的 5 个叶结点构造哈夫曼树，采用每次合并两个最小权值结点的算法，所得哈夫曼树的带权路径长度（WPL）是多少？数据结构简单
A. 61
B. 71
C. 79
D. 83
答案：B. 71
📖 解析：依次合并 2+3=5，5+7=12，9+12=21，12+21=33。WPL 等于每次合并产生的新结点权值之和：5+12+21+33=71；也可按叶深度计算得到 2×3+3×3+7×2+9×2+12×2=71。

A. 5 ns

答案：B. 6 ns

C. OSPF 只能在单一区域内工作，不支持区域划分

答案：B. OSPF 是基于链路状态的协议，路由器通过 LSA 建立链路状态数据库，并用 Dijkstra 算法计算最短路径树

▶某计算机按字节编址，主存地址为 32 位；Cache 采用直接映射，共 1024 行，每行大小为 64 B。访问主存地址 0x12345678 时，其 Cache 行号、标记字段和块内地址分别是多少？计算机组成原理困难
A. 行号 345，标记 0x1234，块内地址 56
B. 行号 0x678，标记 0x1234，块内地址 0x56
C. 行号 345，标记 0x123456，块内地址 120
D. 行号 512，标记 0x1234，块内地址 56
答案：A. 行号 345，标记 0x1234，块内地址 56
📖 解析：每行 64 B，所以块内地址占 log2(64)=6 位；1024 行，所以行号占 log2(1024)=10 位；标记占 32-10-6=16 位。对地址 0x12345678：块内地址 = 0x12345678 & 0x3F = 56；行号 = (地址>>6)&0x3FF = 345；标记 = 地址>>16 = 0x1234。

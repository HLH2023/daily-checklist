▶🧩 LeetCode 每日一题：Distinct Subsequences困难
给定两个字符串 s 和 t，请返回 s 中等于 t 的不同子序列数量。子序列可以通过删除 s 中的一些字符（也可以不删除）且不改变剩余字符相对顺序得到。示例：s="rabbbit"、t="rabbit" 时返回 3；s="babgbag"、t="bag" 时返回 5。
💡 解题思路：设 dp[j] 表示处理当前前缀 s 后，组成 t 前 j 个字符的方案数。初始化 dp[0]=1；扫描 s 的每个字符时，将 j 从后向前更新：若 s[i]==t[j]，则把不选当前字符和选当前字符两类方案相加，即 dp[j+1]+=dp[j]。倒序更新避免当前字符被重复使用。
🔧 题解：状态转移为 dp[i][j]=dp[i-1][j]+dp[i-1][j-1]（当 s[i-1]==t[j-1]），否则 dp[i][j]=dp[i-1][j]。用一维数组倒序压缩空间后，时间复杂度为 O(|s||t|)，额外空间复杂度为 O(|t|)。题目保证答案适合 32 位有符号整数。
from typing import List

class Solution:
    def numDistinct(self, s: str, t: str) -> int:
        dp = [0] * (len(t) + 1)
        dp[0] = 1
        for ch in s:
            for j in range(len(t) - 1, -1, -1):
                if ch == t[j]:
                    dp[j + 1] += dp[j]
        return dp[-1]

▶📐 线代·向量：向量组秩与线性表示线代·向量
α可由β组表示⟹r(α组)≤r(β组)
📌 要点：若向量组 α 中每个向量都可由向量组 β 线性表示，则 α 组的秩不超过 β 组的秩。等价向量组秩相等，但秩相等不必然意味着两个向量组等价；秩为 r 的向量组中任意 r 个线性无关向量可构成极大无关组。
• α 可由 β 组表示时，r(α组)≤r(β组)
• 等价向量组秩相等，但秩相等不是等价的充分条件
• 极大无关组的向量个数等于原向量组的秩

α可由β组表示⟹r(α组)≤r(β组)
🧭 套路：判断表示关系时可转化为矩阵秩；注意‘能表示’给出的是秩的不等式方向。

▶在采用 ltag/rtag 标志的中序线索二叉树中，若结点 p 的左孩子为空而右孩子非空，则下列说法正确的是：数据结构简单
A. ltag=0，p 的左指针指向中序前驱；rtag=1，右指针指向中序后继
B. ltag=1，p 的左指针指向中序前驱；rtag=0，右指针仍指向实际右孩子
C. ltag=1，p 的左指针指向中序后继；rtag=1，右指针指向实际右孩子
D. ltag=0，p 的左指针为空；rtag=0，右指针指向中序后继
答案：B
📖 解析：在线索二叉树中，通常 ltag=0/rtag=0 表示对应指针指向实际孩子，ltag=1/rtag=1 表示对应指针被改作线索。p 无左孩子，所以左指针改为中序前驱并置 ltag=1；p 有实际右孩子，所以 rtag=0，右指针仍指向该右孩子。
▶用 2K×8 位的 RAM 芯片构成 8K×32 位的主存，需要的芯片总数以及每个存储字需要的片选信号数分别是：计算机组成原理简单
A. 4 片，1 个片选信号
B. 8 片，2 个片选信号
C. 16 片，4 个片选信号
D. 32 片，8 个片选信号

A. 取消所有信号量，让三个吸烟者轮流查询桌面状态
B. 用互斥机制保护桌面操作；吸烟者取走材料并完成本轮后通知供应者，供应者收到通知后再放下一组材料
C. 供应者连续放置材料，吸烟者只需对自己的材料执行 wait 操作
D. 每个吸烟者只等待自己拥有的材料，拿到后不必等待另一种材料即可吸烟
答案：B

A. B 的 MAC 地址；C 的 MAC 地址
B. B 的 MAC 地址；默认网关的 MAC 地址
C. 默认网关的 MAC 地址；C 的 MAC 地址

▶关于管程（monitor）的说法，正确的是：操作系统简单
A. 管程允许多个进程同时执行其中的过程，只要它们访问不同变量
B. 管程把共享数据及其操作封装起来，并保证任一时刻最多只有一个进程在管程内执行
C. 条件变量上的 wait 操作不会阻塞调用进程，只会降低其优先级
D. 管程中的 signal 操作可以替代对共享数据的互斥保护
答案：B
📖 解析：管程将共享数据、操作这些数据的过程以及同步机制封装在一起，编译器或运行时保证互斥进入：任一时刻最多一个进程在管程内执行。条件变量用于条件同步，wait 通常会阻塞并释放管程占用，signal 用于唤醒等待者，但二者都不能替代管程本身的互斥保护。

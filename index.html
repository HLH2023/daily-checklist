▶🧩 LeetCode 每日一题：Find Two Non-overlapping Sub-arrays Each With Target Sum中等
给定正整数数组 arr 和整数 target，寻找两个互不重叠且元素和都等于 target 的连续子数组，使它们长度之和最小；若不存在这样的两个子数组，返回 -1。
💡 解题思路：由于数组元素均为正数，可用滑动窗口在线性时间内枚举每个和为 target 的子数组。用 best[i] 记录完全位于下标 i 之前的子数组中最短者；当当前窗口 [left, right] 命中 target 时，与 best[left] 拼接即可保证不重叠，并更新全局最优。
🔧 题解：维护窗口和 total：右端点右移加入元素，total 超过 target 时不断右移 left。每个窗口恰好等于 target 时，长度为 right-left+1；用此前 best[left] 与它组合。best 还要逐位置传递，最终无解返回 -1。时间复杂度 O(n)，空间复杂度 O(n)。
class Solution:
    def minSumOfLengths(self, arr: List[int], target: int) -> int:
        n = len(arr)
        inf = n + 1
        best = [inf] * (n + 1)
        left = 0
        total = 0
        answer = inf

        for right, value in enumerate(arr):
            total += value
            while left <= right and total > target:
                total -= arr[left]
                left += 1

            best[right + 1] = best[right]
            if total == target:
                length = right - left + 1
                if best[left] < inf:
                    answer = min(answer, best[left] + length)
                best[right + 1] = min(best[right + 1], length)

        return -1 if answer == inf else answer

▶采用除留余数法 h(k)=k mod 11，将关键字 23、34、45 依次插入长度为 11 的散列表，并采用线性探测处理冲突。最终三个关键字分别存放在哪些下标？数据结构简单
A. 23→1，34→2，45→3
B. 23→1，34→2，45→4
C. 23→1，34→1，45→2
D. 23→1，34→3，45→5
答案：A
📖 解析：23 mod 11=1，先放入下标1；34 mod 11=1，与23冲突，线性探测放到下标2；45 mod 11=1，依次探测下标2仍冲突，再放到下标3。因此选A。

A. 0xA825
B. 0x2A025
C. 0xA425
D. 0x2A825
答案：A

A. 0x2A345
B. 0x12345
C. 0x2A045
D. 0x12300
答案：A

▶某TCP报文段的首部数据偏移字段值为8，固定首部为20字节，且接收窗口字段为65535。下列关于该报文段首部长度的说法正确的是？计算机网络中等
A. 首部长度为20字节，因为TCP固定首部就是20字节
B. 首部长度为32字节，因为数据偏移以4字节为单位
C. 首部长度为64字节，因为数据偏移字段值为8且按字节计
D. 首部长度为80字节，因为窗口值为65535

▶某指令字长为16位，操作码占6位，剩余地址码分成两个等长地址字段。若每个地址字段用于表示一个操作数地址，则每个地址字段有多少位、最多可表示多少个地址？计算机组成原理简单

D. 10位，1024个
答案：A
📖 解析：地址码总位数为16−6=10位，分成两个等长字段后每个字段为5位；5位二进制地址最多表示2^5=32个地址。因此选A。

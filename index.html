▶🧩 LeetCode 每日一题：Distribute Elements Into Two Arrays IEasy
给定一个下标从 1 开始的整数数组 nums。将 nums 中的元素依次分配到两个数组 arr1 和 arr2：前两个元素分别放入 arr1 和 arr2；之后每个元素放入当前末尾元素更大的那个数组，若相等则放入 arr1。返回先放 arr1、再放 arr2 得到的数组。
💡 解题思路：先把 nums[0] 和 nums[1] 分别放入两个数组。遍历剩余元素，每次比较两个数组的最后一个元素：arr1 末尾更大或相等时放入 arr1，否则放入 arr2。最后拼接两个数组。
🔧 题解：直接模拟题意即可。两个数组始终只需访问末尾元素，因此每个元素处理一次，时间复杂度为 O(n)，额外空间复杂度为 O(n)（存储结果数组）。
class Solution:
    def resultArray(self, nums):
        arr1 = [nums[0]]
        arr2 = [nums[1]]
        for x in nums[2:]:
            if arr1[-1] > arr2[-1]:
                arr1.append(x)
            else:
                arr2.append(x)
        return arr1 + arr2

A. n-1
B. n
C. 0
D. -1
答案：A
📖 解析：顺序栈可用下标 0 到 n-1 存放 n 个元素，栈满时最后一个元素位于下标 n-1，因此 top=n-1。若 top 指向下一个待插入位置，才会采用 top=n；本题已明确 top 指向当前栈顶元素。
▶关于补码加法溢出判断，下列说法正确的是（ ）计算机组成原理简单
A. 两个正数相加结果为负数时发生溢出
B. 正数与负数相加一定发生溢出
C. 两个负数相加结果为正数时不发生溢出
D. 只要最高位产生进位就一定溢出
答案：A
📖 解析：补码中同号数相加可能溢出，异号数相加不会溢出。两个正数相加得到负数，说明结果超出正数表示范围，发生正溢出。两个负数相加得到正数则发生负溢出，因此 C 错；最高位进位不等同于溢出，D 错。

▶采用 CRC 校验，数据位串为 1101，生成多项式对应的位串为 1011。发送端在数据后补 3 个 0 后进行模 2 除法，所得余数和发送位串分别为（ ）计算机网络中等
A. 余数 010，发送位串 1101010
B. 余数 001，发送位串 1101001
C. 余数 011，发送位串 1101011
D. 余数 100，发送位串 1101100
答案：A
📖 解析：补零后的被除数为 1101000。用 1011 做模 2 除法：1101000⊕1011000=0110000，继续对齐后 0110000⊕0101100=0011100，再得 0011100⊕0010110=0001010，余数为低 3 位 010。因此发送位串为 1101 加余数 010，即 1101010。

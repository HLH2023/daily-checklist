▶🧩 LeetCode 每日一题：Maximum Number of Non-Overlapping Substrings困难
给定一个只包含小写字母的字符串 s，找出数量最多的互不重叠子串，使得每个子串中的每个字符都不会出现在该子串之外。返回任意一种满足条件的子串列表。
💡 解题思路：先记录每个字符在字符串中的首次和末次出现位置。对每个字符的首次出现位置尝试构造最小合法区间：扫描区间内字符并不断扩展右端点；若发现某字符的首次出现位置在区间左侧，则该区间不合法。得到所有合法区间后按右端点排序，使用按结束位置优先的贪心策略选择互不重叠区间，即可使区间数量最大。
🔧 题解：设区间 [l,r] 从字符 s[l] 的首次出现位置开始，初始 r 为该字符的末次出现位置。扫描 l 到 r：若遇到字符 c 的 first[c] < l，说明 c 在区间外还有出现，当前区间无效；否则令 r=max(r,last[c])。所有合法区间按右端点升序排列后，若当前区间的左端点大于上一个已选区间的右端点，就选入答案。时间复杂度 O(n)，空间复杂度 O(1)（字母表大小固定）。
class Solution:
    def maxNumOfSubstrings(self, s: str) -> List[str]:
        n = len(s)
        first = [n] * 26
        last = [-1] * 26

        for i, ch in enumerate(s):
            idx = ord(ch) - ord('a')
            first[idx] = min(first[idx], i)
            last[idx] = i

        intervals = []
        for left in first:
            if left == n:
                continue
            right = last[ord(s[left]) - ord('a')]
            i = left
            valid = True
            while i <= right:
                idx = ord(s[i]) - ord('a')
                if first[idx] < left:
                    valid = False
                    break
                right = max(right, last[idx])
                i += 1
            if valid:
                intervals.append((left, right))

        intervals.sort(key=lambda interval: interval[1])
        answer = []
        previous_right = -1
        for left, right in intervals:
            if left > previous_right:
                answer.append(s[left:right + 1])
                previous_right = right
        return answer

A. 23→1，34→2，45→3
B. 23→1，34→2，45→4
C. 23→1，34→1，45→2
D. 23→1，34→3，45→5

▶在32位两级页表系统中，页面大小为4KB，每个页表项占4B。对于逻辑地址0x12345678，页目录索引、二级页表索引和页内偏移分别是多少？操作系统困难
A. 0x48，0x345，0x678
B. 0x123，0x456，0x678
C. 0x48，0x456，0x678
D. 0x12，0x345，0x678
答案：A
📖 解析：4KB=2^12B，所以页内偏移占12位；剩余20位页号由两级各10位组成，因为一页页表可容纳4096/4=1024=2^10个表项。0x12345678右移22位得到页目录索引0x48；取第12至21位得到二级索引0x345；低12位为0x678。因此选A。

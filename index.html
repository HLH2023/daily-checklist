▶🧩 LeetCode 每日一题：Count Nodes Equal to Average of SubtreeMedium
给定一棵二叉树，统计满足条件的结点数量：该结点的值等于其子树（包含结点自身）所有结点值的平均值向下取整。空子树不参与计算。
💡 解题思路：使用后序遍历。处理每个结点时，先得到左、右子树的结点总和与结点数，再把当前结点加入，计算整棵子树的总和与结点数；若当前结点值等于总和除以结点数的向下取整，答案加一。
🔧 题解：DFS返回二元组(sum, count)。后序遍历保证左右子树信息已经准备好；每个结点只访问一次，因此时间复杂度为 O(n)，递归栈空间为 O(h)。Python 的整除 // 正好实现题目要求的向下取整平均值。
class Solution:
    def averageOfSubtree(self, root: Optional[TreeNode]) -> int:
        ans = 0

        def dfs(node):
            nonlocal ans
            if node is None:
                return 0, 0

            left_sum, left_count = dfs(node.left)
            right_sum, right_count = dfs(node.right)
            total = left_sum + right_sum + node.val
            count = left_count + right_count + 1

            if node.val == total // count:
                ans += 1
            return total, count

        dfs(root)
        return ans

B. WPL=71，D 的编码长度为2

▶某系统有资源 R1、R2、R3，初始 Available=(1,1,1)。当前 Allocation 为 P1=(1,0,0)、P2=(0,1,0)、P3=(1,0,1)，Need 为 P1=(1,1,0)、P2=(2,0,1)、P3=(0,1,1)。按进程编号从小到大进行安全性检查时，得到的第一条安全序列是哪一条？操作系统简单
A. P1→P2→P3
B. P2→P1→P3
C. P2→P3→P1
D. 系统不安全，不存在安全序列
答案：A
📖 解析：初始 Work=(1,1,1)，只有 P1 的 Need=(1,1,0) 不超过 Work，P1 完成后释放其 Allocation，Work=(2,1,1)。随后 P2 可完成，Work=(2,2,1)，最后 P3 可完成，因此第一条安全序列为 P1→P2→P3。

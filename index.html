▶🧩 LeetCode 每日一题：Evaluate the Bracket Pairs of a StringMedium
给定字符串 s，其中若干括号对各包含一个非空键；knowledge 是键值对列表。把每个 (key) 替换为对应 value，若键不存在则替换为问号 ?。括号不会嵌套，同一个键可在 s 中重复出现。例如 s='(name)is(age)'，knowledge=[['name','bob'],['age','two']]，结果为 'bobistwo'。
💡 解题思路：先把 knowledge 转成哈希表，然后从左到右扫描 s：遇到左括号时定位对应右括号，取出键并查表；已知键追加其值，未知键追加 '?'；普通字符直接追加。用字符列表收集结果，最后 join。
🔧 题解：每个字符至多被扫描常数次，构建映射和扫描均为线性时间。若 n 为 s 长度、k 为 knowledge 项数，则时间 O(n+k)，空间 O(n+k)（映射与输出）。题目保证括号合法且不嵌套。
from typing import List

class Solution:
    def evaluate(self, s: str, knowledge: List[List[str]]) -> str:
        values = {key: value for key, value in knowledge}
        result = []
        i = 0
        while i < len(s):
            if s[i] == '(':
                j = s.find(')', i + 1)
                key = s[i + 1:j]
                result.append(values.get(key, '?'))
                i = j + 1
            else:
                result.append(s[i])
                i += 1
        return ''.join(result)

固定分配限定 P 可使用的页框数；若采用局部置换，P 只能在自己的 4 个页框中选择牺牲页

总需求为 14 页，恰好不会发生抖动
总需求为 15 页，超过 14 个页框；应考虑暂停或换出至少一个进程以降低多道程序度

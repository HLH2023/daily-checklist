▶🧩 LeetCode 每日一题：Cinema Seat AllocationMedium
电影院有 n 排座位，每排 10 个座位。给定已被预订的座位 reservedSeats，其中每项为 [行号, 座位号]。一个四人家庭必须占用同一排的座位，允许跨过中间过道但两侧各坐两人。返回最多可以安排的四人家庭数量。
💡 解题思路：每排只有三种可能的四连座区间：左侧 [2,3,4,5]、跨过道 [4,5,6,7]、右侧 [6,7,8,9]。未出现预订座位的行一定能安排 2 个家庭；只需用哈希表记录有预订的行，并逐行判断左、中、右区间是否与预订座位冲突。若左、右均可用则安排 2 个，否则三者任一可用则安排 1 个。
🔧 题解：用 defaultdict(int) 为每一行建立座位位掩码。对每个有预订的行，分别检查左区间、右区间和中间区间；左、右都可用时加 2，否则只要存在一个可用区间就加 1。最后加上没有预订的 n-行数乘以 2。时间复杂度 O(m)，空间复杂度 O(m)，m 为预订座位数。
from collections import defaultdict

class Solution:
    def maxNumberOfFamilies(self, n, reservedSeats):
        rows = defaultdict(set)
        for r, s in reservedSeats:
            rows[r].add(s)

        left = {2, 3, 4, 5}
        middle = {4, 5, 6, 7}
        right = {6, 7, 8, 9}
        answer = (n - len(rows)) * 2
        for seats in rows.values():
            can_left = seats.isdisjoint(left)
            can_middle = seats.isdisjoint(middle)
            can_right = seats.isdisjoint(right)
            if can_left and can_right:
                answer += 2
            elif can_left or can_middle or can_right:
                answer += 1
        return answer

▶设机器字长为 8 位，采用补码表示。计算 0110 0101B + 0011 1010B，所得 8 位结果及是否溢出分别为（ ）计算机组成原理中等
A. 1001 1111B，溢出
B. 1001 1111B，不溢出
C. 0110 0101B，溢出
D. 1010 0001B，不溢出
答案：A
📖 解析：两个操作数最高位均为 0，表示正数：0110 0101B=101，0011 1010B=58，真值和为 159，超出 8 位补码正数范围 127。按模 256 运算，101+58=159=1001 1111B，结果符号位变为 1，故发生正溢出，选 A。

▶🧩 LeetCode 每日一题：Stone Game VIIIHard
给定整数数组 stoneValue，Alice 和 Bob 轮流从数组左端拿走至少一个石子并获得所拿石子的总分；Alice 的第一次操作必须拿走至少两个石子。双方均采取最优策略，返回 Alice 最终得分与 Bob 最终得分之差的最大值。
💡 解题思路：用前缀和表示从开头拿走若干石子的得分。若当前已经考虑到前缀 i，选择把前 i+1 个石子作为一次操作后，当前得分差为 prefix[i] 减去对手在后续状态中的最优得分；也可以把选择继续延后，沿用后一个状态。因此状态转移为 dp[i]=max(dp[i+1], prefix[i]-dp[i+1])，只需从后向前滚动维护一个变量。由于 Alice 的第一次操作至少拿两个石子，最终答案从 prefix[1] 对应的状态开始。
🔧 题解：先计算前缀和 prefix。令 ans=prefix[n-1]，表示在最后一个可转移状态之后的基准值；然后令 i 从 n-2 递减到 1，执行 ans=max(ans, prefix[i]-ans)。循环结束时 ans 即 Alice 在允许首步至少拿两个石子的条件下的最大得分差。时间复杂度 O(n)，额外空间复杂度 O(n)（若保留前缀和）；也可以原地复用输入数组保存前缀和。
from itertools import accumulate

class Solution:
    def stoneGameVIII(self, stoneValue: list[int]) -> int:
        prefix = list(accumulate(stoneValue))
        ans = prefix[-1]
        for i in range(len(prefix) - 2, 0, -1):
            ans = max(ans, prefix[i] - ans)
        return ans

▶设发送一个数据帧所需时间为 T。在纯 ALOHA、时隙 ALOHA 和采用载波侦听的 CSMA 中，下列关于冲突特性的说法正确的是（ ）计算机网络中等
A. 纯 ALOHA 的易受冲突时间为 2T，时隙 ALOHA 的易受冲突时间为 T；CSMA 通过侦听可减少冲突但不能完全消除冲突
B. 纯 ALOHA 和时隙 ALOHA 的易受冲突时间都为 T，CSMA 能完全消除冲突
C. 纯 ALOHA 的易受冲突时间为 T，时隙 ALOHA 的易受冲突时间为 2T；CSMA 不需要退避
D. 时隙 ALOHA 只能在有线网络使用，CSMA 只能在无线网络使用
答案：A
📖 解析：纯 ALOHA 中帧在任意时刻发送，前后各一个帧时长内到达的帧都可能造成冲突，因此易受冲突时间为 2T；时隙 ALOHA 将发送起点限制在时隙边界，易受冲突时间降为 T。CSMA 先侦听信道，能够降低冲突概率，但传播时延等因素仍可能导致冲突，不能保证完全无冲突。

A. 两次出队分别返回 a、b；第二次出队后必须令 front=null，入队 c 后 rear=H
B. 两次出队分别返回 a、b；第二次出队后 front=rear=H，入队 c 后 H.next 指向 c 且 rear 指向 c

答案：B

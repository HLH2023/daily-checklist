▶🧩 LeetCode 每日一题：Minimum Add to Make Parentheses ValidMedium
给定只含 '(' 和 ')' 的字符串 s，每次可以在任意位置插入一个括号。若字符串为空、可由两个有效括号串拼接，或形如 (A)（A 有效），则称其有效。求使 s 有效所需的最少插入次数。例：s = '())'，答案为 1；s = '((('，答案为 3。
💡 解题思路：从左到右扫描，维护尚未匹配的左括号数 left。遇到 '(' 就令 left 加一；遇到 ')' 时若 left>0，则匹配一个左括号并令 left 减一，否则这个右括号前缺少一个左括号，答案加一。扫描结束后，剩余 left 个未匹配左括号各需补一个右括号。
🔧 题解：用 additions 统计扫描中遇到的多余右括号，用 left 统计最后剩余的左括号。最少插入数为 additions + left。每个字符只处理一次，时间复杂度 O(n)，额外空间复杂度 O(1)。
class Solution:
    def minAddToMakeValid(self, s: str) -> int:
        left = 0
        additions = 0
        for ch in s:
            if ch == '(':
                left += 1
            elif left > 0:
                left -= 1
            else:
                additions += 1
        return additions + left

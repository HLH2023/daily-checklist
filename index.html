▶🧩 LeetCode 每日一题：Remove Invalid ParenthesesHard
给定一个由左括号、右括号和小写字母组成的字符串 s，删除最少数量的括号，使结果字符串有效；返回所有可能的结果。字母不能删除。例：s = "()())()"，可返回 ["(())()", "()()()"]。
💡 解题思路：按删除次数进行广度优先搜索：从原字符串开始，逐层尝试删除一个括号。首次发现有效字符串时，该层所有有效结果都是最少删除方案，收集后即可返回；不再搜索更深层。每层用集合去重，并只删除括号字符。
🔧 题解：用队列保存当前层候选字符串，并以 visited 防止重复状态。每层先检查所有候选是否有效；若有有效项就返回整层结果。否则对每个字符串逐个删除括号生成下一层。有效性检查通过余额计数完成：前缀余额不得为负，结尾余额必须为零。最坏情况下状态数量较多，设字符串长度为 n，时间复杂度可达 O(n·2^n)，空间复杂度 O(2^n)。
from typing import List

class Solution:
    def removeInvalidParentheses(self, s: str) -> List[str]:
        def valid(text: str) -> bool:
            balance = 0
            for ch in text:
                if ch == '(':
                    balance += 1
                elif ch == ')':
                    balance -= 1
                    if balance < 0:
                        return False
            return balance == 0

        level = {s}
        visited = {s}
        while level:
            answers = [text for text in level if valid(text)]
            if answers:
                return answers

            next_level = set()
            for text in level:
                for i, ch in enumerate(text):
                    if ch not in '()':
                        continue
                    candidate = text[:i] + text[i + 1:]
                    if candidate not in visited:
                        visited.add(candidate)
                        next_level.add(candidate)
            level = next_level
        return ['']

A. 能；哈希值相同即可证明发送者身份和报文来源

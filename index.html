▶🧩 LeetCode 每日一题：Maximum Nesting Depth of the ParenthesesEasy
给定一个有效括号字符串 s，定义某一对括号的深度为它内部嵌套的括号对数加 1。返回 s 中括号的最大嵌套深度。例如：s = "(1+(2*3)+((8)/4))+1"，最大深度为 3。
💡 解题思路：从左到右扫描，遇到左括号就把当前深度加一，并更新最大值；遇到右括号就把当前深度减一。由于输入保证括号有效，扫描过程中深度不会小于 0，结束时回到 0。
🔧 题解：时间复杂度 O(n)，额外空间复杂度 O(1)。只需维护当前深度和历史最大深度，不必使用栈。
class Solution:
    def maxDepth(self, s: str) -> int:
        depth = ans = 0
        for ch in s:
            if ch == '(':
                depth += 1
                ans = max(ans, depth)
            elif ch == ')':
                depth -= 1
        return ans

▶🧩 LeetCode 每日一题：Find the Minimum and Maximum Number of Nodes Between Critical Points中等
给定一个单链表，将同时大于前后节点的节点或同时小于前后节点的节点称为关键点。返回任意两个不同关键点之间的最小距离和最大距离；若关键点少于两个，返回 [-1, -1]。距离按节点在链表中的位置之差计算。
💡 解题思路：只需一次遍历并维护相邻三个节点。用 prev、cur、next 判断 cur 是否为局部极大或局部极小；记录第一个和最近一个关键点的位置。每发现一个新关键点，更新与上一个关键点的距离（得到最小值），最后用最后一个位置减第一个位置得到最大值。
🔧 题解：从位置 1 开始遍历中间节点，严格使用 > 或 <，相等时不能判为关键点。关键点不足两个时返回 [-1, -1]；否则返回 [min_gap, last_pos - first_pos]。时间复杂度 O(n)，额外空间复杂度 O(1)。
def nodesBetweenCriticalPoints(head):
    prev = head
    cur = head.next
    pos = 1
    first = -1
    last = -1
    min_gap = float('inf')

    while cur and cur.next:
        nxt = cur.next
        is_critical = (cur.val > prev.val and cur.val > nxt.val) or \
                      (cur.val < prev.val and cur.val < nxt.val)
        if is_critical:
            if first == -1:
                first = pos
            else:
                min_gap = min(min_gap, pos - last)
            last = pos
        prev = cur
        cur = nxt
        pos += 1

    if first == -1 or first == last:
        return [-1, -1]
    return [min_gap, last - first]

▶📐 线代·第1章·行列式：方阵行列式性质线代·第1章·行列式
|A^T|=|A|；|kA|=k^n|A|；|AB|=|A||B|；|A^m|=|A|^m
📌 要点：n 阶方阵转置不改变行列式；矩阵整体数乘 k 时，行列式乘以 k^n；乘积的行列式等于行列式之积。注意矩阵乘法本身通常不交换，但 |AB| 与 |BA| 相等。
• |kA| 中 k 作用于 n 行（或 n 列），所以因子是 k^n 而不是 k
• |AB|=|A||B| 对同阶方阵成立，且不要求 AB=BA
• |A^m|=|A|^m 可直接用于幂的行列式计算
默写核心结论：＿＿＿
|A^T|=|A|；|kA|=k^n|A|；|AB|=|A||B|；|A^m|=|A|^m
🧭 套路：先辨认是整矩阵数乘还是某一行（列）数乘，再决定行列式因子的次数。
▶📐 线代·第2章·矩阵及其运算：分块矩阵运算线代·第2章·矩阵及其运算
|A C;O B|=|A||B|；换位块=(-1)^(mn)|A||B|；分块转置=A^T B^T;C^T D^T交换
📌 要点：分块矩阵的加减和数乘按对应块进行，乘法遵守普通矩阵乘法规则但块之间一般不可交换。分块三角矩阵的行列式等于对角块行列式之积；分块对角矩阵的幂可分别对各对角块求幂。
• 分块必须保证维数匹配，块乘法不能把块当作普通标量随意交换
• 上（下）三角分块矩阵的行列式等于对角块行列式之积
• 分块转置不仅要对每块转置，还要交换非对角块的位置
默写核心结论：＿＿＿
|A C;O B|=|A||B|；换位块=(-1)^(mn)|A||B|；分块转置=A^T B^T;C^T D^T交换
🧭 套路：遇到分块行列式先观察是否为分块三角形；遇到分块转置牢记‘每块转置并转置块的位置’。

▶一棵完全二叉树共有 10 个结点，按从上到下、从左到右编号为 1～10。下列说法正确的是（ ）。数据结构简单

B. 结点 6 一定是叶子结点

答案：B
📖 解析：完全二叉树按层序编号时，编号大于 ⌊n/2⌋ 的结点是叶子。n=10，⌊10/2⌋=5，因此 6～10 都是叶子，只有 B 正确；5 号结点可能有孩子。

A. 关中断方法可以保证多处理机环境下所有处理器互斥
B. Test-and-Set 指令具有原子性，适合实现自旋锁
C. Swap 指令会使临界区一定不会发生忙等

▶关于 IEEE 802.11 无线局域网的基本工作模式，下列说法正确的是（ ）。计算机网络中等
A. 基础设施模式中，所有无线站点必须直接两两通信，不能经过接入点
B. 自组网（Ad hoc）模式需要固定的无线接入点统一转发帧
C. 基础设施模式由接入点（AP）连接无线站点，并可通过分布式系统接入有线网络
D. 802.11 只能工作在自组网模式，不能支持基础设施模式
答案：C
📖 解析：基础设施模式以 AP 为中心，无线站点通过 AP 接入分布式系统，并可连接有线网络。Ad hoc 是无中心的临时网络，不要求固定 AP；因此 A、B、D 均与两种模式的定义不符。

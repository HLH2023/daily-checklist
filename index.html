▶🧩 LeetCode 每日一题：Unique 3-Digit Even NumbersEasy
给定一个数字数组 digits，每个数字最多使用一次，返回由这些数字组成的所有互不重复的三位偶数；三位数的百位不能为 0。
💡 解题思路：枚举 100 到 998 之间的所有偶数，并用计数表判断该数的每个数字出现次数是否不超过 digits 中的供给。枚举范围只有 450 个数，逻辑直接且能自然处理重复数字。
🔧 题解：用 Counter 统计 digits 中各数字的频次。对每个三位偶数转成字符串，再统计其各位数字；若每种数字的需求量都不超过原数组频次，就加入答案。结果按数值升序生成，时间复杂度为 O(900)，额外空间复杂度为 O(1)。
from collections import Counter
from typing import List

class Solution:
    def findEvenNumbers(self, digits: List[int]) -> List[int]:
        available = Counter(digits)
        answer = []

        for number in range(100, 1000, 2):
            need = Counter(str(number))
            if all(need[d] <= available[int(d)] for d in need):
                answer.append(number)

        return answer

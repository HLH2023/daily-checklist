▶🧩 LeetCode 每日一题：Make Lexicographically Smallest Array by Swapping Elements中等
给定一个下标从 0 开始的正整数数组 nums 和正整数 limit。一次操作中，若 |nums[i]-nums[j]|≤limit，就可以交换任意两个下标 i、j 的元素。请返回经过任意次操作后能够得到的字典序最小数组。例：nums=[1,5,3,9,8]、limit=2 时返回 [1,3,5,8,9]。
💡 解题思路：把 nums 的数值排序。若排序后相邻两个数的差不超过 limit，则它们可以通过连续交换连成同一个连通分量；一个分量内的元素可以任意重排。对每个分量，取其中的数值升序排列，再把这些数依次放到该分量原下标的升序位置，就能使整个数组字典序最小。
🔧 题解：先按数值排序并按相邻差值≤limit 划分分组。每组内收集原下标并排序，同时把组内数值排序；将最小值分配给最小原下标，依次完成重排。排序主导时间复杂度为 O(n log n)，额外空间复杂度为 O(n)。
from typing import List

class Solution:
    def lexicographicallySmallestArray(self, nums: List[int], limit: int) -> List[int]:
        n = len(nums)
        pairs = sorted((value, index) for index, value in enumerate(nums))
        ans = [0] * n
        left = 0

        while left < n:
            right = left
            while (right + 1 < n
                   and pairs[right + 1][0] - pairs[right][0] <= limit):
                right += 1

            values = sorted(value for value, _ in pairs[left:right + 1])
            indices = sorted(index for _, index in pairs[left:right + 1])
            for index, value in zip(indices, values):
                ans[index] = value
            left = right + 1

        return ans

▶一棵非空树共有 n 个结点。关于该树边数的说法正确的是？数据结构简单
A. n 条
B. n-1 条
C. n+1 条
D. 取决于树的度，无法确定
答案：B
📖 解析：树是连通且无环的图。每加入一个新结点，只需且必需通过一条边接入已有部分，因此 n 个结点恰有 n-1 条边。树的度分布、层次和高度会变化，但不影响这一结论。
▶有 8 位数据位，采用能够纠正 1 位错误的海明码，校验位数 r 应满足 2^r≥8+r+1。r 的最小值是多少？计算机组成原理简单
A. 3
B. 4
C. 5
D. 8
答案：B
📖 解析：r=3 时，2^3=8<8+3+1=12，不满足条件；r=4 时，2^4=16≥8+4+1=13，因此最少需要 4 位校验位。海明码总长度为 8+4=12 位，并可定位、纠正 1 位错误。

A. 两个 VLAN 属于同一个广播域，广播帧会互相转发
B. VLAN 10 与 VLAN 20 是不同广播域，同一 VLAN 内可二层通信，跨 VLAN 需三层设备转发
C. VLAN 只能划分冲突域，不能划分广播域
D. 只要使用同一台交换机，两个 VLAN 内主机就一定能直接通信
答案：B

▶采用 CRC，数据位串为 1101，生成多项式对应的二进制除数为 1011。发送端在数据后补 3 个 0 后进行模 2 除法，所得 CRC 余数是多少？计算机组成原理困难
A. 000
B. 001
C. 010
D. 111
答案：B
📖 解析：生成多项式 1011 的阶数为 3，所以先将 1101 扩展为 1101000。按模 2 除法逐位异或：1101000 除以 1011 的最后 3 位余数为 001，因此 CRC 校验码为 001，实际发送码字为 1101001。接收端将码字再除以 1011，余数应为 000。

▶数学：极限定义（ε-δ 语言）📐 高数中等
极限是高等数学的第一块基石。ε-δ 语言把"无限接近"翻译成精确的数学不等式，是证明极限存在与否的唯一严格工具。
核心定义：lim(x→x₀) f(x)=A ⟺ 对任意 ε>0，存在 δ>0，当 0<|x−x₀|<δ 时，恒有 |f(x)−A|<ε。数列版本（ε-N 语言）：lim(n→∞) xₙ=A ⟺ ∀ε>0，∃N∈N⁺，当 n>N 时 |xₙ−A|<ε。
记忆口诀："ε 任意小，δ 跟着找；ε-N 证数列，ε-δ 证函数"。
▶LeetCode：Maximum Length Substring With Two Occurrences简单
给定字符串 s，求最长子串的长度，使其中每个字符出现的次数都不超过 2 次。
思路：滑动窗口。右指针扩展，当窗口内某字符计数 > 2 时左指针收缩直到合法；每次更新最大长度。O(n) 时间。
关键点：字符计数用频率数组/哈希即可；注意"子串"连续，"子序列"不连续。

▶① 数据结构：下列程序段的时间复杂度为？数据结构简单
A. O(√n)　B. O(log₂n)　C. O(n)　D. O(nlog₂n)
int i = 1, s = 0; while (i <= n) { s += i; i *= 2; }
答案：B
解析：循环变量 i 按 2 的幂增长（1, 2, 4, 8, …），设循环执行 k 次，则 2ᵏ ≤ n，即 k ≤ log₂n。循环体为常数时间，故时间复杂度为 O(log₂n)。常见复杂度排序：O(1) < O(log n) < O(n) < O(nlog n) < O(n²) < O(2ⁿ)。
▶② 计组：关于冯·诺依曼"存储程序"思想，正确的是？计组简单
A. 只有指令存放在存储器中，数据存放在运算器中
B. 指令和数据以同等地位存放在存储器中，按地址访问
C. 程序只能顺序执行，不能跳转
D. 存储器中只能存放数据，指令由控制器直接产生
答案：B
解析：存储程序思想的核心：指令和数据均以二进制形式、以同等地位存放在存储器中，按地址寻访（指令按地址顺序取出执行，也可跳转）。A 错：数据同样存放在存储器；C 错：程序可跳转，这正是存储程序方式的优势；D 错：指令由程序员预先编写存入内存，控制器负责取指执行而非凭空产生。
▶③ OS（融合计组）：用户程序执行陷入指令请求系统服务，下列说法错误的是？操作系统中等
A. 用户态与内核态由程序状态字寄存器 PSW 中的状态位标识
B. 用户态下 CPU 只能执行非特权指令，不能执行特权指令
C. 陷入指令属于特权指令，只能在用户态执行
D. 从用户态切换到内核态的唯一途径是中断/异常（含陷入），返回用户态需执行特权指令
答案：C
解析：陷入（访管）指令是非特权指令——恰恰是用户态下唯一能主动触发"请求内核服务"的指令；而特权指令（如 I/O 指令、置中断屏蔽字、清 TLB 等）只能在内核态执行，用户态执行特权指令会触发非法指令异常陷入内核。A、B、D 均正确。融合考点：CPU 状态由 PSW 标识（计组）、中断/异常是用户态→内核态的唯一途径（OS）。
▶④ 网络：OSI 中实现"端到端"可靠传输并负责差错控制、流量控制的层次是？网络简单
A. 物理层　B. 数据链路层　C. 网络层　D. 传输层
答案：D
解析：传输层提供端到端（进程到进程）的传输服务，负责差错控制、流量控制、拥塞控制（如 TCP）。区分三个关键词：物理层传比特流；数据链路层是相邻结点间的点到点传输；网络层是主机到主机的分组转发（尽力而为、不可靠）。"端到端"是传输层的标志词。
▶⑤ 网络（融合）：TCP/IP 模型与 OSI 参考模型的对应关系，正确的是？网络困难
A. TCP/IP 的网络接口层对应 OSI 的网络层
B. TCP/IP 的应用层对应 OSI 的会话层、表示层和应用层
C. TCP/IP 的网际层对应 OSI 的数据链路层
D. TCP/IP 模型共七层，与 OSI 逐层完全对应
答案：B
解析：TCP/IP 四层与 OSI 七层的压缩对应：网络接口层 ≈ 物理层 + 数据链路层（A、C 错）；网际层 ≈ 网络层；传输层 ≈ 传输层；应用层 ≈ 会话层 + 表示层 + 应用层三层合一（B 对，TCP/IP 没有独立的会话层与表示层）。D 错：TCP/IP 共四层。记忆："接口压两层、应用压三层、中间一一对"。

▶极限定义（ε-δ 语言）高数中等
lim(x→x₀) f(x) = A ⟺ ∀ε>0，∃δ>0，当 0<|x−x₀|<δ 时，|f(x)−A|<ε
lim(n→∞) xₙ = A ⟺ ∀ε>0，∃N∈N⁺，当 n>N 时，|xₙ−A|<ε
理解要点：① ε 是"误差标准"，要任意小都能满足；δ 随 ε 变化，只要求存在不要求具体值 ② 极限刻画的是 x 趋近 x₀ 时的趋势，与 f(x₀) 是否有定义、等于多少无关 ③ 极限性质：唯一性、局部有界性、保号性。
证明套路：从 |f(x)−A| 出发放大，反解出 |x−x₀| 的约束，令 δ 等于该表达式即可。典型：|(2x+1)−3| = 2|x−1|，取 δ = ε/2。
小题：用 ε-δ 语言证明 lim(x→1)(2x+1) = 3。答案：对 ∀ε>0，取 δ=ε/2，当 0<|x−1|<δ 时，|(2x+1)−3|=2|x−1|<2·(ε/2)=ε，得证。

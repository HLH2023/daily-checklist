▶🧩 LeetCode 每日一题：Longest Valid ParenthesesHard
给定一个只包含 '(' 和 ')' 的字符串，求其中最长有效（格式正确且连续）的括号子串长度。
💡 解题思路：使用动态规划。令 dp[i] 表示以下标 i 结尾的最长有效括号子串长度；只有 s[i]=')' 时才可能更新。若前一字符是 '('，可拼接 dp[i-2]+2；若前一字符也是 ')'，检查与当前位置匹配的左括号位置 j=i-dp[i-1]-1，匹配成功则拼接 dp[i-1]+2，并加上更早的有效后缀 dp[j-1]。
🔧 题解：从左到右维护 dp 数组并同步更新最大值。遇到 '()' 型结尾时接上前面的有效段；遇到 '( ... ))' 型结尾时，跳过前一段有效后缀找到可能匹配的 '('，再把内部、外层和紧邻之前的有效段合并。时间复杂度 O(n)，空间复杂度 O(n)。
class Solution:
    def longestValidParentheses(self, s: str) -> int:
        n = len(s)
        dp = [0] * n
        best = 0
        for i in range(1, n):
            if s[i] == ')':
                if s[i - 1] == '(':
                    dp[i] = 2 + (dp[i - 2] if i >= 2 else 0)
                else:
                    j = i - dp[i - 1] - 1
                    if j >= 0 and s[j] == '(':
                        dp[i] = dp[i - 1] + 2 + (dp[j - 1] if j >= 1 else 0)
                best = max(best, dp[i])
        return best

▶有向图含顶点 S、A、B、C，边权为 S→A(4)、S→B(5)、A→B(-2)、B→C(3)、A→C(6)。以 S 为源点，Bellman-Ford 算法求得 C 的最短距离是多少？数据结构中等
A. 3
B. 5
C. 6
D. 8
答案：B
📖 解析：路径 S→A→B→C 的长度为 4+(-2)+3=5；S→B→C 为 8，S→A→C 为 10，因此最短距离为 5。Bellman-Ford 对所有边最多松弛 |V|-1 轮，并可再扫描一轮检测可达负环。
▶某处理器在一个时钟周期内能够判断多条相互独立的指令并将其发射到多个功能部件执行，这种技术最直接体现了什么？计算机组成原理简单
A. 超标量多发射
B. 单指令流水线
C. 微程序控制
D. 主存交叉编址
答案：A

▶🧩 LeetCode 每日一题：Image OverlapMedium
给定两个大小相同的 n×n 二进制矩阵 img1 和 img2。将其中一个矩阵在平面上平移（不旋转），使两个矩阵重叠；重叠区域中两个矩阵同时为 1 的位置数量称为重叠值。请返回所有平移方式中的最大重叠值。平移后超出矩阵边界的部分不计入。
💡 解题思路：把平移表示为行偏移 dr 和列偏移 dc，分别枚举 dr、dc∈[-n+1,n-1]。对每个偏移，只统计 img1[i][j] 与 img2[i+dr][j+dc] 在两者都位于矩阵内且都为 1 的位置数，维护最大值。因为矩阵只有 n×n，直接枚举行列偏移和矩阵位置即可。
🔧 题解：枚举全部 (2n−1)² 种平移。对于每个平移，遍历 img1 的每个 1，并计算它平移后的坐标是否落在 img2 内；若对应位置也是 1，则当前重叠数加一。时间复杂度 O(n⁴)，空间复杂度 O(1)。也可以只保存两个矩阵中 1 的坐标，将复杂度优化为与 1 的个数相关，但暴力平移法更直观。
from typing import List

class Solution:
    def largestOverlap(self, img1: List[List[int]], img2: List[List[int]]) -> int:
        n = len(img1)
        best = 0

        for dr in range(-n + 1, n):
            for dc in range(-n + 1, n):
                overlap = 0
                for i in range(n):
                    for j in range(n):
                        ni, nj = i + dr, j + dc
                        if 0 <= ni < n and 0 <= nj < n:
                            overlap += img1[i][j] & img2[ni][nj]
                best = max(best, overlap)

        return best

▶空 AVL 树依次插入关键字 30、20、10。插入 10 后出现图示的失衡，此时应采用哪种调整？数据结构简单
A. LL 型，先对结点 30 做一次右旋
B. RR 型，先对结点 30 做一次左旋
C. LR 型，先对结点 20 做左旋，再对结点 30 做右旋
D. RL 型，先对结点 30 做右旋，再对结点 20 做左旋
答案：A
📖 解析：30、20、10 依次插入后，失衡结点 30 的左孩子 20 的左子树增高，属于 LL 型失衡。对失衡结点 30 做一次右旋即可，旋转后 20 成为根，10 和 30 分居左右。
▶关于 Cache 的写回法（write-back），下列说法正确的是：计算机组成原理简单
A. CPU 每次写 Cache 都必须同步写入主存
B. 只有被修改过的 Cache 块被替换时，才需要写回主存，通常需要脏位
C. 写回法不允许 Cache 中的数据被修改
D. 写回法不需要考虑 Cache 块替换时的数据一致性
答案：B
📖 解析：写回法先只更新 Cache，并将该块标记为脏块；当脏块被替换时才把最新内容写回主存，因此能减少写主存次数，但需要脏位记录块是否被修改。A 描述的是写直达法。
▶某系统页面大小为 1KB，逻辑地址 2500 所在的逻辑页映射到物理帧 7。若页内偏移保持不变，则该逻辑地址对应的物理地址是多少？操作系统简单
A. 3524
B. 5572
C. 7620
D. 8192
答案：C

▶某 Cache 命中时的总访问时间为 2 ns，发生失配时的总访问时间为 42 ns，Cache 命中率为 90%。采用平均访问时间 = 命中率×命中时间 + 失配率×失配时间，则平均访问时间是多少？计算机组成原理困难
A. 4 ns
B. 5 ns
C. 6 ns
D. 8 ns
答案：C
📖 解析：失配率为 1−90%=10%。平均访问时间 = 0.9×2+0.1×42=1.8+4.2=6 ns。题目给出的失配时总访问时间已经包含本次访问的完整时间，因此直接按两种情况加权平均，不要再额外重复加一次命中时间。

▶🧩 LeetCode 每日一题：Stone Game VHard
Alice 和 Bob 继续玩石子游戏。一排 n 堆石子，价值为 stones[i]。Alice 先手，两人轮流进行。每回合，当前玩家选择一个现存的分段（初始为整排石子）并把它拆成两段，使得两段价值之和相等，然后只保留其中价值较大的一段（若两段相等则任选一段，另一段被取走并计入该玩家的分数）；若不存在相等拆分，则该玩家不能行动（不产生分数），对手接着行动。游戏一直到只剩一段石子（不能再拆）为止，所有玩家得分的总和即为其总分。双方均最优操作，返回 Alice 能获得的最大分数。该题是区间 DP 的经典应用：定义 f[l][r] 为某一方在区间 [l, r] 上先手所能获得的最高分，通过枚举切分点并利用前缀和 O(1) 判断左、右半段价值是否相等（相等时才可操作，只能取较大那一半，另一半计入操作者分数）。
💡 解题思路：状态设计为区间 DP：f[l][r] = 在区间 [l, r] 上操作的玩家能获得的最大分数。枚举切分点 k（l ≤ k < r），设左段和为 L = sum(l,k)、右段和为 R = sum(k+1,r)：① 若 L < R，说明只有拆分出左段更小才能操作，操作者只能取右段（R 计入其分数），并轮到对手在右段 (k+1, r) 先手，故 f[l][r] = max(R + f[k+1][r])；② 若 L > R，对称地 f[l][r] = max(L + f[l][k])；③ 若 L == R，操作者可任选一段保留，分数 = 段和 + 对方在保留段先手的结果，即 f[l][r] = max(L + f[l][k], R + f[k+1][r])；④ 若 L < R 且进一步说明以当前 k 拆分时右段更大，则只取右段。最终答案 f[1][n]（对应整排）。
🔧 题解：① 用前缀和 pres 快速求任意区间和；② 区间长度从小到大递推（先算小区间），f[l][r] 的初始值可由「不可拆分」情形（用枚举所有 k 都无法满足 L == R 的关系）退化到只能选择允许的情形，因此要仔细处理：只有当 L == R 时操作者才真正获得那一半分数并转移；若对某 k 有 L != R，事实上该切分点根本不能作为合法的「相等拆分」，需忽略（Stone Game 规则要求拆出的两段价值相等）。对每个子区间枚举全部 k，按 L 与 R 的关系分三种情况取最大值即可。③ 答案即 f[1][n]，n 个石子，前缀和 + O(n^3) 枚举（可用记忆化搜索，等价于自顶向下的区间 DP）。注意：本规则下「必须相等才能拆」，与常见取较大半堆版本的转移略有差异，逐项核对 L==R 分支尤其关键。
class Solution:
    def stoneGameV(self, stones):
        n = len(stones)
        pre = [0] * (n + 1)
        for i, v in enumerate(stones):
            pre[i + 1] = pre[i] + v
        from functools import lru_cache
        @lru_cache(None)
        def f(l, r):
            if l == r:
                return 0
            total = pre[r + 1] - pre[l]
            best = 0
            # 枚举切分点 k：左段 [l,k] 右段 [k+1,r]
            left = 0
            for k in range(l, r):
                left += stones[k]
                right = total - left
                if left < right:
                    best = max(best, left + f(l, k))   # 左段较小→操作者取左段（左段价值计入其分，对手在左段先手）
                elif left > right:
                    best = max(best, right + f(k + 1, r))
                else:
                    best = max(best, left + f(l, k), right + f(k + 1, r))
            return best
        return f(0, n - 1)

▶📐 高数·第1天·极限：复合极限逆向判断第1天
f严格单调：lim f(g(x))存在⟹lim g(x)存在或g(x)趋于无穷
📌 要点：复合函数极限的反向判断：若外层函数 f 严格单调，且 lim f(g(x)) 存在，则可推出内层 lim g(x) 一定存在（或 g(x)→±∞）。逆否表述：若 lim g(x) 不存在且 g(x) 不趋于无穷，则 lim f(g(x)) 必不存在。这是解决「已知复合极限判断内层极限」一类逆向题的常用结论，前提是 f 严格单调（可逆），否则不能由 f(g(x)) 的极限反推 g(x) 的极限。
• f 严格单调 ⟹ 存在反函数 f⁻¹，可由外极限反推内极限
• lim f(g(x)) 存在 ⟹ lim g(x) 存在或 g(x)→±∞（否则复合极限不存在）
• 若 f 不单调（如 f(x)=x² 非单射），仅凭 f(g(x)) 极限无法唯一确定 g(x) 极限
f严格单调时，lim f(g(x))存在⟹＿＿＿
lim g(x)存在或g(x)→±∞
🧭 套路：判定时先检查外层是否严格单调；再考察内层极限是否存在或趋于无穷，两者都不满足则复合极限一定不存在。
▶📐 高数·第1天·极限：极限保号性第1天
lim f(x)>0⟹局部 f(x)>0；局部 f(x)>0⟹lim≥0（可为0）
📌 要点：极限的保号性：若 lim(x→x0) f(x) = A > 0，则存在 x0 的某个去心邻域，使该邻域内 f(x) > 0；A < 0 时对称地 f(x) < 0。反过来，若在 x0 附近（去心邻域内）恒有 f(x) > 0 且极限存在，则极限值 A ≥ 0（注意可以等于 0，不能推出 A > 0）。核心思想：ε 取任意小的正数，由极限定义有 A−ε < f(x) < A+ε，取 ε < A 即可保证 f(x) > 0。
• A>0（或 A<0）⟹ 局部函数值与极限同号
• 局部恒>0 且极限存在 ⟹ 极限≥0（可为0），这是一个「只能取弱不等式」的易错点
• 取 ε = |A|/2 即可由 |f(x)−A|<ε 直接得到 f(x) 与 A 同号
lim f(x)>0⟹x充分接近时＿＿＿；f(x)>0且极限存在⟹极限＿＿＿
f(x)>0；≥0
🧭 套路：求「局部 f(x)>0 ⟹ lim ≥?」这类题目注意结论是 ≥0 而非 >0；正方向（充分性）可用极限的 ε−δ 定义证明。
▶📐 线代·行列式与矩阵：方阵行列式性质线代·行列式与矩阵
|Aᵀ|=|A|；|kA|=kⁿ|A|；|AB|=|A||B|；|Aᵐ|=|A|ᵐ
📌 要点：方阵行列式的运算性质：转置不改变行列式（|Aᵀ|=|A|）；数乘矩阵时行列式为 kⁿ|A|（n 为阶数，这是与「某一行提公因子」的区别，整体提因子每行都乘 k）；乘积的行列式等于行列式的乘积 |AB|=|A||B|（即使 AB≠BA，两边的行列式仍相等）；由此推出 |Aᵐ|=|A|ᵐ，以及 A 可逆时 |A⁻¹|=|A|⁻¹。
• |Aᵀ|=|A|，行列式按行展开与按列展开结果一致
• |kA|=kⁿ|A|（n 阶方阵），注意 n 次幂
• |AB|=|A||B| 对任意同阶方阵成立，与矩阵乘法顺序无关
默写核心结论：＿＿＿
|A^T|=|A|；|kA|=k^n|A|；|AB|=|A||B|；|A^m|=|A|^m
🧭 套路：区分「某一行乘 k」（行列式 ×k）与「整个矩阵乘 k」（行列式 ×kⁿ）；利用 |AB|=|A||B| 常可绕过复杂矩阵乘积直接算行列式。
▶📐 线代·行列式与矩阵：分块矩阵运算线代·行列式与矩阵
|A C;O B|=|A||B|；换位块=(-1)^(mn)|A||B|；分块转置=Aᵀ Bᵀ;Cᵀ Dᵀ交换
📌 要点：分块矩阵的运算：分块加减、数乘按块进行；分块乘法与普通矩阵乘法规则一致（块乘法不可交换，注意乘法顺序）；分块对角矩阵的行列式 = 各对角块行列式之积（如 |A C;O B|=|A||B|，上三角分块同理），若对换两个对角块位置，行列式乘以 (-1)^(mn)；分块矩阵的转置需把子块自身转置并交换位置：[A B;C D]ᵀ = [Aᵀ Cᵀ;Bᵀ Dᵀ]；分块对角幂 = 各块取幂；可结合 Laplace 展开理解。
• 分块矩阵乘法按「块元」套用普通规则，块不可交换
• 分块三角矩阵 |A C;O B|=|A||B|；换位后再乘 (-1)^(mn)
• 分块转置：先整体转置（交换子块位置），再对每个子块取转置
默写核心结论：＿＿＿
|A C;O B|=|A||B|；换位块=(-1)^(mn)|A||B|；分块转置=A^T B^T;C^T D^T交换
🧭 套路：记忆技巧：分块转置 = 先将子块按矩阵转置的「对角线翻转」换位，再对每个子块单独转置。算大矩阵行列式时优先考虑分块三角化。

▶下列关于顺序表和链表的比较，说法错误的是（ ）数据结构简单
A. 顺序表支持随机存取，可在 O(1) 时间内按位置访问元素；链表只能顺序存取
B. 在表头插入/删除元素，顺序表需要移动大量元素，链表只需修改少量指针
C. 顺序表不需存储指针域，存储密度高；链表每个结点额外占用指针域，存储密度较低
D. 顺序表适合频繁插入删除的场景，链表适合频繁按位置随机访问的场景
答案：D
📖 解析：顺序表（数组实现）按位置访问是 O(1) 随机存取，但插入/删除平均需移动 n/2 个元素，代价大；链表插入/删除仅修改指针 O(1)（需先找到位置），但访问必须从头顺序遍历。因此「频繁插入删除」适合链表，「频繁按位置随机访问」适合顺序表，D 把两者说反了。C 正确：链表每个结点需额外的指针域，存储密度（数据占比）低于顺序表。
▶设机器字长为 8 位，采用补码表示。已知 [x]补 = 1110 1100B，则 x 的十进制真值为（ ）计算机组成原理中等
A. +108
B. -20
C. -108
D. +20
答案：B
📖 解析：负数补码求真值：符号位为 1（负数），将数值位按位取反后加 1 得真值绝对值。1110 1100B → 数值位 110 1100B 取反得 001 0011B，再加 1 得 001 0100B = 20（十进制），符号为负，故 x = -20。也可用「补码整体按权展开再 -2^8」校验：1110 1100B = 2^7 - 20 - 2^8 思路下实质结果同为 -20。注意补码 8 位表示范围 -128 ~ +127，0 的表示唯一，均与此题契合。
▶关于进程的创建与终止，下列说法错误的是（ ）操作系统简单
A. 在 UNIX/Linux 中，fork 创建的子进程初始获得父进程地址空间的一份拷贝（利用写时复制技术）
B. 父进程先终止而其子进程仍在运行，这些子进程称为孤儿进程，通常被 init（1 号）进程收养
C. 子进程已终止但父进程尚未对其调用 wait/waitpid 回收其 PCB 等资源，此时子进程处于僵尸状态（Zombie）
D. 父进程可以通过调用 exit 系统调用直接终止它所创建的子进程
答案：D
📖 解析：exit 是进程终止自身执行的系统调用；父进程无法通过 exit 直接终止子进程，终止子进程通常借助信号（如 kill、SIGKILL）或由操作系统在子进程结束时回收。父进程的作用是对已终止的子进程调用 wait/waitpid 回收其资源。A 正确：fork 采用 copy-on-write（写时复制）优化。B 正确：孤儿进程由 init 收养。C 正确：子进程已终止但未被父进程回收时残留 PCB，进入僵尸状态。

A. ADSL 采用频分复用技术，在同一对双绞线上同时传送电话语音信号与高速数据信号
B. FTTx 属于光纤接入，其中 FTTH 表示光纤到户，FTTB 表示光纤到楼
C. HFC 是混合光纤同轴电缆网，基于有线电视网的同轴电缆提供宽带上网，用户端需 Cable Modem

▶设机器字长为 8 位，采用反码进行加减运算（符号位有进位时执行循环进位，即 end-around carry）。计算 (-25) + (-18)，其十进制真值为（ ）计算机组成原理困难
A. -43
B. -44
C. -42
D. -41
答案：A
📖 解析：8 位反码：25=0001 1001B，-25 反码=1110 0110B（数值位按位取反）；18=0001 0010B，-18 反码=1110 1101B。两数反码相加：1110 0110 + 1110 1101 = 1 1101 0011（最高位产生进位），按反码运算规则将溢出的进位循环回加：1101 0011B + 1 = 1101 0100B。结果符号位为 1（负数），将其数值位 101 0100B 按位取反得 010 1011B = 43，故真值为 -43。校验：(-25)+(-18)=-43 正确。注意反码中 0 有 +0（0000 0000）与 -0（1111 1111）两种表示，且反码表示不了补码才有的 -128。

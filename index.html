▶🧩 LeetCode 每日一题：Lexicographically Smallest Palindromic Permutation Greater Than Target困难
给定两个长度均为 n 的小写字母串 s 和 target。请返回 s 的一个回文排列中严格大于 target 的字典序最小者；若不存在，返回空串。n≤300。例：s=baba、target=abba 时返回 baab；s=baba、target=bbaa 时返回空串。
💡 解题思路：回文排列存在的必要条件是最多只有一个字符出现奇数次；回文左半部分的字符多重集由每个字符频数除以 2 得到，奇数长度时中间字符固定为唯一的奇数频数字符。字典序比较时先比较左半部分：先构造不小于 target 左半部分的最小多重集排列；若它严格更大，直接镜像即可。若左半部分相同，再比较完整回文；若仍不大于 target，则寻找左半部分多重集排列的下一个严格更大排列。
🔧 题解：先统计 26 个字母频数并检查奇数频数个数。用回溯式的字典序后继构造：从右向左尝试保留 target 前缀，在某一位放置比 target 当前字符大的最小可用字符，剩余字符升序填充。这样得到的候选是多重集排列中大于给定下界的最小者，整体复杂度 O(n·26)，空间复杂度 O(n)。
from typing import List

class Solution:
    def _next_perm_at_least(self, cnt: List[int], bound: str, strict: bool) -> str | None:
        m = len(bound)

        # bound 本身可用时，非严格下界直接返回它。
        left = cnt[:]
        exact = True
        for ch in bound:
            k = ord(ch) - ord('a')
            if left[k] == 0:
                exact = False
                break
            left[k] -= 1
        if exact and not strict:
            return bound

        # 从右向左寻找最靠后的“变大”位置，保留尽可能长的前缀。
        for i in range(m - 1, -1, -1):
            rest = cnt[:]
            ok = True
            for ch in bound[:i]:
                k = ord(ch) - ord('a')
                if rest[k] == 0:
                    ok = False
                    break
                rest[k] -= 1
            if not ok:
                continue
            start = ord(bound[i]) - ord('a') + 1
            for k in range(start, 26):
                if rest[k] == 0:
                    continue
                rest[k] -= 1
                suffix = ''.join(chr(j + ord('a')) * rest[j] for j in range(26))
                return bound[:i] + chr(k + ord('a')) + suffix
        return None

    def _palindrome(self, left: str, center: str) -> str:
        return left + center + left[::-1]

    def lexicographicallySmallestPalindromicPermutationGreaterThanTarget(self, s: str, target: str) -> str:
        freq = [0] * 26
        for ch in s:
            freq[ord(ch) - ord('a')] += 1
        odd = [i for i, c in enumerate(freq) if c % 2]
        if len(odd) > 1:
            return ''

        center = chr(odd[0] + ord('a')) if odd else ''
        half = [c // 2 for c in freq]
        left_len = len(s) // 2
        bound = target[:left_len]

        left = self._next_perm_at_least(half, bound, strict=False)
        if left is not None:
            candidate = self._palindrome(left, center)
            if candidate > target:
                return candidate

        left = self._next_perm_at_least(half, bound, strict=True)
        return '' if left is None else self._palindrome(left, center)

▶📐 线代·特征值与特征向量：施密特正交化线代·特征值与特征向量

• 第一步取 β1=α1
• 后续向量减去在已得正交向量上的投影
• 正交组再分别除以自身长度即可单位化

▶设模式串 P="ababaca"，采用 0 下标且 next[0]=-1 的 KMP 定义。已匹配 P[0..4]="ababa" 后，在 P[5] 处失配时，应回退到哪个模式串下标继续比较？数据结构简单
A. 0
B. 1
C. 2
D. 3
答案：D
📖 解析：已匹配前缀为 ababa，失配时考察它的最长相等真前缀和真后缀。最长的是 aba，长度为 3，因此 next[5]=3，应让 P[3] 与当前主串字符继续比较。
▶采用偶校验传输 8 位数据 10110010。该数据中 1 的个数为 4，则应附加的偶校验位是多少？计算机组成原理简单
A. 0
B. 1
C. 由接收端随机决定
D. 无法确定，必须知道数据位宽之外的信息
答案：A
📖 解析：偶校验要求数据位和校验位中 1 的总数为偶数。10110010 中已有 4 个 1，是偶数，所以附加校验位为 0。奇偶校验可检测某些错误（尤其奇数位翻转），但不能定位错误位置，也不能可靠检测偶数位同时翻转。
▶进程 A、B、C 同时到达，运行时间分别为 4、3、2，静态优先级分别为 2、1、3（数值越小优先级越高）。采用非抢占式优先级调度，平均等待时间是多少？操作系统中等
A. 10/3
B. 19/3
C. 3
D. 5
答案：A
📖 解析：调度顺序为 B、A、C。B 等待 0，A 等待 3，C 等待 3+4=7，总等待时间为 10，平均等待时间为 10/3。所有进程同时到达，所以等待时间不需要再扣除到达时刻。

A. 仅有 AA→P1；两帧都从所有端口广播
B. 有 AA→P1、BB→P2；第二帧仅转发到 P1
C. 有 BB→P1、AA→P2；第二帧仅转发到 P2

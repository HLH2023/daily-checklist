▶🧩 LeetCode 每日一题：Smallest Stable Index II中等
给定长度为 n 的整数数组 nums 和整数 k。对每个下标 i，定义不稳定度为 max(nums[0..i]) − min(nums[i..n−1])。若该值不超过 k，则 i 是稳定下标。请返回最小的稳定下标；若不存在则返回 −1。示例：nums=[5,0,1,4], k=3 时返回 3；nums=[3,2,1], k=1 时返回 −1。
💡 解题思路：先从右向左预处理后缀最小值 suffix_min[i]=min(nums[i..n−1])，再从左向右维护前缀最大值 prefix_max=max(nums[0..i])。对每个 i 检查 prefix_max−suffix_min[i] 是否不超过 k，第一个满足条件的下标就是答案。
🔧 题解：题目要求左、右区间都包含当前位置，因此 prefix_max 和 suffix_min 都必须包含 nums[i]。后缀最小值一次逆序扫描，前缀最大值一次正序扫描，时间复杂度 O(n)，额外空间复杂度 O(n)。
from typing import List

class Solution:
    def firstStableIndex(self, nums: List[int], k: int) -> int:
        n = len(nums)
        suffix_min = [0] * n
        suffix_min[-1] = nums[-1]
        for i in range(n - 2, -1, -1):
            suffix_min[i] = min(nums[i], suffix_min[i + 1])

        prefix_max = nums[0]
        for i, value in enumerate(nums):
            prefix_max = max(prefix_max, value)
            if prefix_max - suffix_min[i] <= k:
                return i
        return -1

▶一棵二叉树的先序遍历序列为 A、B、D、E、C、F、G，中序遍历序列为 D、B、E、A、F、C、G。该二叉树的后序遍历序列是：数据结构简单
A. D、E、B、F、G、C、A
B. A、B、D、E、C、F、G
C. D、B、E、F、C、G、A
D. G、F、C、E、D、B、A
答案：A
📖 解析：先序第一个 A 是根；由中序序列可知左子树为 D、B、E，右子树为 F、C、G。继续按先序和中序划分可得左子树根 B、孩子 D/E，右子树根 C、孩子 F/G。后序按左—右—根访问，得到 D、E、B、F、G、C、A。
▶关于 SRAM 与 DRAM，下列说法正确的是：计算机组成原理简单
A. SRAM 使用电容存储信息，必须周期性刷新
B. DRAM 使用触发器存储信息，断电后仍能保持内容
C. SRAM 通常不需要刷新、速度较快但成本较高；DRAM 需要刷新、容量密度较高
D. SRAM 和 DRAM 都不需要刷新，且 DRAM 的访问速度通常更快
答案：C
📖 解析：SRAM 用双稳态触发器保存信息，只要供电就不需要周期性刷新，速度快、功耗和成本通常较高；DRAM 以电容存储电荷，存在漏电，需要定期刷新，但单元面积小、集成度高、单位容量成本低。
▶五位哲学家围坐在圆桌旁，每人先拿左边筷子，再拿右边筷子；筷子一次只能被一人持有。若五人同时拿起左边筷子，系统将发生：操作系统困难
A. 互斥失效，多个哲学家同时使用同一根筷子
B. 死锁：每人占有一根筷子并等待另一根，形成环路等待
C. 饥饿：所有哲学家都能继续运行但永远不能进餐
D. 缺页中断：筷子不足会自动换入新的资源
答案：B

B. PROM 通常只能一次性编程，EPROM 可用紫外线擦除后重新写入

▶🧩 LeetCode 每日一题：Number of Sets of K Non-Overlapping Line Segments中等
数轴上有 n 个点，第 i 个点的坐标为 i。要求恰好画出 k 条互不重叠的线段，每条线段至少覆盖两个点，端点必须是整数坐标；线段可以共享端点，也不要求覆盖全部点。返回方案数并对 10^9+7 取模。
💡 解题思路：关键是把每条线段看成一对有序端点，并处理相邻线段允许共享端点这一条件。经典计数结果为 C(n+k−1, 2k)：相当于在 n+k−1 个位置中选择 2k 个端点，选择结果按顺序唯一对应一组合法线段。也可以用二维动态规划验证这一组合数关系。
🔧 题解：令 N=n+k−1，则答案是组合数 C(N,2k)。由于 N≤1998，先计算 0 到 N 的阶乘，再用费马小定理求逆元：C(N,r)=N!·(r!)^(MOD−2)·((N−r)!)^(MOD−2) mod MOD。这里 N−2k=n−k−1≥0，满足题目约束。时间复杂度 O(n+k)，空间复杂度 O(n+k)。
class Solution:
    def numberOfSets(self, n: int, k: int) -> int:
        MOD = 10**9 + 7
        N = n + k - 1
        r = 2 * k

        fact = [1] * (N + 1)
        for i in range(1, N + 1):
            fact[i] = fact[i - 1] * i % MOD

        return (fact[N]
                * pow(fact[r], MOD - 2, MOD)
                * pow(fact[N - r], MOD - 2, MOD)) % MOD

▶某页式虚拟存储系统的页大小为 4 KiB，采用字节编址。逻辑地址为 0x12345，则该地址的页号和页内偏移分别是（ ）。计算机组成原理简单
A. 页号 0x12，页内偏移 0x345
B. 页号 0x123，页内偏移 0x45
C. 页号 0x1，页内偏移 0x2345
D. 页号 0x13，页内偏移 0x245
答案：A
📖 解析：4 KiB=4096=0x1000，因此页内偏移占低 12 位。将 0x12345 按 0x1000 分解：页号为 0x12345//0x1000=0x12，页内偏移为 0x12345%0x1000=0x345。

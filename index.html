▶🧩 LeetCode 每日一题：Brace Expansion IIHard
给定由小写字母、逗号和花括号构成的表达式：字母表示单元素集合；逗号表示集合并集；相邻表达式表示两集合元素的笛卡尔积拼接。返回表达式代表的所有不同单词，按字典序排列。例：{a,b}{c,{d,e}} → [ac,ad,ae,bc,bd,be]。
💡 解题思路：用递归下降解析文法：parse_union 解析逗号分隔的并集，parse_concat 解析相邻项的笛卡尔积拼接，parse_atom 解析字母或花括号子表达式。每层用 set 自动去重，最后排序。
🔧 题解：解析时用共享下标扫描字符串。花括号内递归解析并集，遇到逗号或右花括号结束当前拼接段；拼接通过集合两两组合完成。题目保证表达式合法，复杂度取决于中间结果集合大小。
class Solution:
    def braceExpansionII(self, expression: str) -> list[str]:
        i = 0
        n = len(expression)

        def parse_union():
            nonlocal i
            result = parse_concat()
            while i < n and expression[i] == ',':
                i += 1
                result |= parse_concat()
            return result

        def parse_concat():
            nonlocal i
            result = {""}
            while i < n and expression[i] not in ',}':
                if expression[i] == '{':
                    i += 1
                    part = parse_union()
                    i += 1  # 跳过 }
                else:
                    part = {expression[i]}
                    i += 1
                result = {a + b for a in result for b in part}
            return result

        return sorted(parse_union())

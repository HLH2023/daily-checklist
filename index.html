▶🧩 LeetCode 每日一题：Minimum Operations to Reduce X to ZeroMedium
给定一个整数数组 nums 和整数 x。每一步可以从数组最左端或最右端移除一个元素，并将 x 减去该元素的值。请返回使 x 恰好减为 0 所需移除元素的最少数量；如果无法做到，返回 -1。
💡 解题思路：把问题转化为：保留一个连续子数组，使其元素和等于 sum(nums)-x，并让这个子数组尽可能长。于是答案就是 n 减去最长满足目标和的连续子数组长度。由于 nums 为正整数，可以用滑动窗口在线性时间内维护窗口和；若目标和为 0，则不保留任何元素，答案为 n。
🔧 题解：设 target=sum(nums)-x。双指针维护窗口 [left,right]：右端逐步扩展并累加窗口和；当窗口和大于 target 时不断移动 left 缩小窗口；窗口和等于 target 时更新最长长度。最后若没有找到窗口返回 -1，否则返回 n-max_len。时间复杂度 O(n)，空间复杂度 O(1)。
from typing import List

class Solution:
    def minOperations(self, nums: List[int], x: int) -> int:
        target = sum(nums) - x
        n = len(nums)
        if target < 0:
            return -1

        left = 0
        window_sum = 0
        longest = -1
        for right, value in enumerate(nums):
            window_sum += value
            while left <= right and window_sum > target:
                window_sum -= nums[left]
                left += 1
            if window_sum == target:
                longest = max(longest, right - left + 1)

        return -1 if longest == -1 else n - longest

A. Seq=3000，Ack=7000；1MSL

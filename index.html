▶🧩 LeetCode 每日一题：Shortest and Lexicographically Smallest Beautiful StringMedium
给定二进制字符串 s 和正整数 k。若子串中 1 的个数恰好为 k，则称其为 beautiful。请返回所有 beautiful 子串中长度最短且字典序最小的一个；若不存在则返回空串。
💡 解题思路：记录字符串中所有字符 1 的位置。任意恰好包含 k 个 1 的最短候选，都可以取为某一组连续 k 个 1 从第一个 1 到第 k 个 1 的闭区间；首尾再加入 0 只会变长。枚举每个连续 k 个 1，截取对应子串，先按长度取最短，再在同长度候选中取字典序最小者。
🔧 题解：设 ones 为所有 1 的下标列表。对 i 从 0 到 len(ones)-k，候选子串为 s[ones[i]:ones[i+k-1]+1]，它恰好含 k 个 1。维护最短长度 best_len 和字典序最小的答案 ans：候选更短时替换，长度相等且候选更小时替换。若 1 的总数少于 k，返回空串。时间复杂度 O(n^2)（n≤100；切片与比较的总成本按最坏情况计），空间复杂度 O(n)。
class Solution:
    def shortestBeautifulSubstring(self, s: str, k: int) -> str:
        ones = [i for i, ch in enumerate(s) if ch == '1']
        if len(ones) < k:
            return ""

        ans = ""
        best_len = len(s) + 1
        for i in range(len(ones) - k + 1):
            candidate = s[ones[i]:ones[i + k - 1] + 1]
            if len(candidate) < best_len or (len(candidate) == best_len and candidate < ans):
                best_len = len(candidate)
                ans = candidate
        return ans

▶3 个进程同时在时刻 0 到达，运行时间分别为 P1=6、P2=2、P3=4，采用非抢占式 SJF。平均等待时间为（ ）。操作系统简单
A. 2
B. 8/3
C. 10/3
D. 4
答案：B
📖 解析：非抢占式 SJF 的执行顺序为 P2(2)、P3(4)、P1(6)。三者等待时间分别为 0、2、6，平均等待时间=(0+2+6)/3=8/3。SJF 在所有进程同时到达且无抢占时可使平均等待时间较小，但长作业可能饥饿。

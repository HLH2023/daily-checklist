▶🧩 LeetCode 每日一题：Maximum Length Substring With Two OccurrencesEasy
求最长子串长度，使其中每个字符出现次数不超过 2 次。
💡 解题思路：滑动窗口：右指针扩展，计数超过 2 时左指针收缩
🔧 题解：维护窗口内字符计数数组，O(n) 一次遍历。
def maxLength(s):
    cnt = {}
    l = ans = 0
    for r, ch in enumerate(s):
        cnt[ch] = cnt.get(ch, 0) + 1
        while cnt[ch] > 2:
            cnt[s[l]] -= 1
            l += 1
        ans = max(ans, r - l + 1)
    return ans

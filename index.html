▶🧩 LeetCode 每日一题：Valid ParenthesesEasy
给定只包含字符 '('、')'、'{'、'}'、'['、']' 的字符串 s，判断括号是否有效。有效字符串须满足：左括号必须由相同类型的右括号闭合，闭合顺序正确，且每个右括号都有对应左括号。
💡 解题思路：使用栈保存尚未匹配的左括号。遇到左括号就入栈；遇到右括号时，若栈为空或栈顶不是对应的左括号，立即判无效，否则弹栈。扫描结束后栈必须为空。
🔧 题解：用字典建立右括号到左括号的映射，逐字符检查。时间复杂度 O(n)，最坏额外空间复杂度 O(n)。
class Solution:
    def isValid(self, s: str) -> bool:
        pairs = {')': '(', ']': '[', '}': '{'}
        stack = []
        for ch in s:
            if ch in pairs:
                if not stack or stack[-1] != pairs[ch]:
                    return False
                stack.pop()
            else:
                stack.append(ch)
        return not stack

▶关于流水线中的数据冒险及其处理，下列说法正确的是？计算机组成原理简单
A. 旁路/转发可缩短 RAW 相关等待；即使有转发，经典流水线中的紧邻 load-use 相关通常仍需停顿
B. 旁路转发只能解决控制冒险，不能处理数据相关
C. 插入气泡会改变程序指令的语义执行顺序
D. WAR 和 WAW 属于所有简单顺序 5 段流水线必然出现的结构冒险
答案：A

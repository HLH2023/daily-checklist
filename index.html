▶🧩 LeetCode 每日一题：Find X Value of Array I中等
给定一个正整数数组 nums 和正整数 k。恰好进行一次操作：删除一个前缀和一个后缀（两者可以为空），但剩余数组必须非空。对每个 x（0≤x<k），统计剩余元素乘积除以 k 的余数为 x 的操作数，返回长度为 k 的数组 result。
💡 解题思路：删除前缀和后缀后留下的部分一定是一个非空连续子数组，因此问题等价于统计所有非空连续子数组的乘积模 k。扫描数组，维护以上一个位置结尾的连续子数组按乘积余数分类的数量；加入当前元素后，单元素子数组产生一个新状态，旧状态全部乘上当前元素并对 k 取模。每个位置得到的状态累加到答案。
🔧 题解：设 prev[r] 表示以前一个元素结尾、乘积模 k 等于 r 的连续子数组数量。对 nums[i]，先令 cur[nums[i] % k] 加 1，再把每个 prev[r] 转移到 cur[(r * (nums[i] % k)) % k]。将 cur 累加到 result，最后返回 result。时间复杂度 O(nk)，空间复杂度 O(k)。
from typing import List

class Solution:
    def resultArray(self, nums: List[int], k: int) -> List[int]:
        ans = [0] * k
        prev = [0] * k

        for value in nums:
            v = value % k
            cur = [0] * k
            cur[v] += 1  # 只包含当前元素的子数组
            for residue, count in enumerate(prev):
                if count:
                    cur[(residue * v) % k] += count
            for residue, count in enumerate(cur):
                ans[residue] += count
            prev = cur

        return ans

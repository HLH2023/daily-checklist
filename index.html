▶🧩 LeetCode 每日一题：Kth Smallest Amount With Single Denomination CombinationHard
给定不同面额的硬币数组 coins 和整数 k。每种面额的硬币都有无限枚，但一次构成金额时不能混用不同面额。所有可构成的金额就是各面额的正整数倍的并集，返回其中第 k 小的不同金额。
💡 解题思路：对答案 x 二分查找，统计不超过 x 的可构成金额数量。面额 c 能产生 floor(x/c) 个倍数；不同面额的倍数集合可能重叠，因此用容斥原理枚举所有非空子集，子集交集的周期是这些面额的最小公倍数，奇数个集合加上，偶数个集合减去。计数不少于 k 时收缩右边界。
🔧 题解：先为每个面额子集预计算最小公倍数。count(x) 按子集大小奇偶对 x//lcm 求和，得到不超过 x 的不同可构成金额数。答案上界可取 min(coins)*k，因为最小面额的前 k 个倍数一定可构成；对 [1, min(coins)*k] 进行二分。预计算和每次计数均遍历 2^n 个子集，时间复杂度 O(2^n log(min(coins)·k))，空间复杂度 O(2^n)。
from math import gcd

class Solution:
    def findKthSmallest(self, coins, k):
        n = len(coins)
        size = 1 << n
        lcms = [1] * size

        for mask in range(1, size):
            bit = mask & -mask
            i = bit.bit_length() - 1
            prev = mask ^ bit
            g = gcd(lcms[prev], coins[i])
            lcms[mask] = lcms[prev] // g * coins[i]

        def count(x):
            total = 0
            for mask in range(1, size):
                lcm_value = lcms[mask]
                if lcm_value <= x:
                    contribution = x // lcm_value
                    if mask.bit_count() & 1:
                        total += contribution
                    else:
                        total -= contribution
            return total

        left, right = 1, min(coins) * k
        while left < right:
            mid = (left + right) // 2
            if count(mid) >= k:
                right = mid
            else:
                left = mid + 1
        return left

▶关于同一进程内线程的说法，正确的是（ ）操作系统简单
A. 同一进程的线程共享进程地址空间，但各自拥有程序计数器、寄存器集合和栈
B. 线程拥有独立于所属进程的地址空间，因此线程间必须通过管道通信
C. 任意线程切换都必然引起从用户态到内核态的切换
D. 一个线程结束后，所属进程中的其他线程一定全部结束
答案：A

▶在 8 位机器字长下，位串 11101100 作为无符号数和补码有符号数分别表示多少？再将它与补码位串 00010101 相加，所得 8 位结果及有符号溢出情况是（ ）计算机组成原理困难
A. 无符号数 236，有符号数 -20；结果为 00000001，补码有符号运算不溢出
B. 无符号数 236，有符号数 -20；结果为 00000001，补码有符号运算发生溢出
C. 无符号数 108，有符号数 -20；结果为 11111111，补码有符号运算不溢出
D. 无符号数 236，有符号数 20；结果为 00000001，补码有符号运算不溢出
答案：A
📖 解析：11101100 的无符号值为 128+64+32+8+4=236；最高位为 1，按 8 位补码解释时其值为 236-256=-20。与 00010101（十进制 21）相加得到 1 00000001，保留低 8 位为 00000001。-20+21=1 在补码表示范围内，没有有符号溢出；最高位产生进位本身也不能作为补码溢出的判据。

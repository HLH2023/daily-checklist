▶🧩 LeetCode 每日一题：Generate ParenthesesMedium
给定 n 对括号，编写函数生成所有由 n 对括号组成且有效的括号组合。有效括号串要求任意前缀中左括号数量不少于右括号数量，且最终左右括号数量相等。
💡 解题思路：回溯构造字符串，分别记录已使用的左、右括号数。左括号数小于 n 时可以追加“(”；只有右括号数小于左括号数时才可以追加“)”，从而保证任意前缀有效。长度达到 2n 时收集结果。
🔧 题解：采用深度优先搜索枚举合法前缀，剪枝掉右括号多于左括号的分支。除输出结果外，递归栈深度为 O(n)；结果数量为第 n 个 Catalan 数。
class Solution:
    def generateParenthesis(self, n: int) -> list[str]:
        ans = []
        path = []

        def dfs(left: int, right: int) -> None:
            if len(path) == 2 * n:
                ans.append("".join(path))
                return
            if left < n:
                path.append("(")
                dfs(left + 1, right)
                path.pop()
            if right < left:
                path.append(")")
                dfs(left, right + 1)
                path.pop()

        dfs(0, 0)
        return ans

▶某文件系统的盘块大小为 1 KiB，块指针占 4 B。一个文件控制块有 10 个直接地址项和 1 个一级间接地址项；间接索引块全部用于存放数据块地址，索引块自身不计入文件数据容量。该文件最多可存放多少字节的数据？操作系统困难
A. 262,144 B（256 KiB）
B. 266,240 B（260 KiB）
C. 272,384 B（266 KiB）
D. 1,048,576 B（1 MiB）
答案：C
📖 解析：一个索引块可存放 1024 B÷4 B=256 个块地址，加上 10 个直接地址，共可寻址 266 个数据块。最大数据容量为 266×1024 B=272,384 B，即 266 KiB；索引块本身不算文件数据块。

▶🧩 LeetCode 每日一题：Count Commas in Range简单
给定整数 n，返回把区间 [1,n] 中的所有整数按标准数字格式书写时使用的逗号总数。标准格式要求从右向左每三位数字插入一个逗号，少于4位的数字不含逗号。例如 n=1002 时，只有 1,000、1,001、1,002 各含一个逗号，答案为3。
💡 解题思路：按逗号所在的位级统计，而不是逐个格式化整数。对于因子 factor=1000、1000000、……，所有不小于 factor 的数都至少在该位级贡献一个逗号，因此该位级的贡献为 max(0,n-factor+1)。依次累加直到 factor>n。
🔧 题解：枚举 1000 的幂次。factor=1000 统计千位逗号，factor=1000000 统计百万位逗号，以此类推；每个数在每个达到的位级恰好贡献一个逗号，所以不会重复或漏计。n≤10^5 时循环最多执行一次，时间复杂度 O(log_1000 n)，额外空间复杂度 O(1)。
class Solution:
    def countCommas(self, n: int) -> int:
        total = 0
        factor = 1000
        while factor <= n:
            total += n - factor + 1
            factor *= 1000
        return total

▶采用孩子兄弟表示法将森林转换为二叉树。若森林中三棵树的根从左到右依次为 A、D、F，则在转换后的二叉树中，A、D、F 之间的指针关系是：数据结构简单
A. A 的左指针指向 D，D 的左指针指向 F
B. A 的右指针指向 D，D 的右指针指向 F
C. A 的右指针指向 F，F 的左指针指向 D
D. A、D、F 仍分别作为三棵独立二叉树的根，不发生指针连接
答案：B
📖 解析：孩子兄弟表示法中，结点的左指针指向第一个孩子，右指针指向下一个兄弟。森林各棵树的根在原森林中互为兄弟，因此第一棵树根 A 的右指针指向第二棵树根 D，D 的右指针指向第三棵树根 F。

▶在 RIP 路由中，路由器 A 到邻居 B 的代价为1。A 收到 B 通告的某网络 N 的距离为4跳，则 A 计算到 N 的候选距离应为：计算机网络中等
A. 3跳
B. 4跳

答案：C
📖 解析：RIP 使用距离向量思想，A 经 B 到 N 的距离等于 A 到 B 的链路代价加上 B 通告的距离，即 1+4=5 跳。RIP 的最大可达距离是15跳，16跳表示不可达；本题候选距离为5跳。

A. 二叉树先序对应一般树先根，二叉树中序对应一般树后根
B. 二叉树先序对应一般树后根，二叉树中序对应一般树先根

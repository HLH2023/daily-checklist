▶🧩 LeetCode 每日一题：Check if There Is a Valid Parentheses String PathHard
给定一个只含 '(' 和 ')' 的 m×n 网格，从左上角出发，只能向右或向下走到右下角。判断是否存在一条路径，使路径经过的括号字符依次组成一个合法括号字符串。
💡 解题思路：括号前缀的余额（左括号数减右括号数）不能为负，走到终点时必须为 0。用 dp[i][j] 保存到达格子 (i,j) 时所有可能的非负余额集合；从上方和左方合并状态，再按当前格子的括号将余额加一或减一。若余额为负则丢弃；若余额大于剩余步数，或与剩余步数奇偶性不匹配，也不可能归零，可提前剪枝。路径总格数必须为偶数。
🔧 题解：时间复杂度 O(mn(m+n))，空间复杂度 O(mn(m+n))（余额状态最多为 O(m+n)）。
from typing import List

class Solution:
    def hasValidPath(self, grid: List[List[str]]) -> bool:
        m, n = len(grid), len(grid[0])
        # 每条路径含 m+n-1 个括号；合法括号串长度必须为偶数
        if (m + n - 1) % 2 != 0 or grid[0][0] != '(' or grid[m - 1][n - 1] != ')':
            return False

        dp = [[set() for _ in range(n)] for _ in range(m)]
        for i in range(m):
            for j in range(n):
                if i == 0 and j == 0:
                    prev = {0}
                else:
                    prev = set()
                    if i > 0:
                        prev.update(dp[i - 1][j])
                    if j > 0:
                        prev.update(dp[i][j - 1])

                step = 1 if grid[i][j] == '(' else -1
                remaining = (m - 1 - i) + (n - 1 - j)
                for balance in prev:
                    new_balance = balance + step
                    if new_balance >= 0 and new_balance <= remaining and (remaining - new_balance) % 2 == 0:
                        dp[i][j].add(new_balance)

        return 0 in dp[m - 1][n - 1]

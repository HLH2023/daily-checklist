▶🧩 LeetCode 每日一题：Distinct Subsequences II困难
给定一个仅含小写英文字母的字符串 s，请返回 s 的不同非空子序列数量，结果对 10^9+7 取模。子序列通过删除若干字符（也可以不删）得到，且不能改变剩余字符的相对顺序。例如 s="aba" 时，不同非空子序列共有 6 个：a、b、ab、aa、ba、aba。
💡 解题思路：令 dp 表示处理当前前缀后不同子序列的数量（包含空序列），last[c] 记录上一次处理字符 c 之前的 dp 值。加入字符 c 时，所有旧子序列都可以选或不选它，得到 2×dp；其中以 c 结尾的重复子序列需要扣除 last[c]。更新为 new_dp=2×dp-last[c]，再令 last[c]=dp、dp=new_dp。最后减去空序列。
🔧 题解：一维动态规划：dp 初值为 1，表示空序列；遍历 s 中每个字符，保存旧 dp 后按 new_dp=(2*dp-last[c])%MOD 更新，并把 last[c] 设为旧 dp。重复字符的扣除保证每个非空子序列只计数一次，最终返回 (dp-1)%MOD。时间复杂度 O(n)，额外空间复杂度 O(1)（字符集固定为 26 个小写字母）。
class Solution:
    def distinctSubseqII(self, s: str) -> int:
        MOD = 10**9 + 7
        dp = 1  # 包含空序列
        last = [0] * 26
        for ch in s:
            i = ord(ch) - ord('a')
            old_dp = dp
            dp = (2 * dp - last[i]) % MOD
            last[i] = old_dp
        return (dp - 1) % MOD

▶在树的孩子兄弟表示法中，一个结点的左指针和右指针分别表示什么？数据结构简单
A. 左指针指向双亲，右指针指向孩子
B. 左指针指向第一个孩子，右指针指向下一个兄弟
C. 左指针指向下一个兄弟，右指针指向第一个孩子
D. 左指针和右指针都只表示该结点在原树中的孩子
答案：B
📖 解析：孩子兄弟表示法（左孩子右兄弟表示法）把一般树转换为二叉树：左指针连接该结点的第一个孩子，右指针连接该结点的下一个兄弟。因此一个结点的所有孩子可沿左指针进入后不断沿右指针访问。
▶用 4K×8 位 RAM 芯片构成 16K×32 位主存，需要的芯片总数以及字扩展形成的存储体组数分别是：计算机组成原理简单
A. 8 片，2 组
B. 16 片，4 组
C. 16 片，8 组
D. 32 片，4 组
答案：B
📖 解析：先做位扩展：32/8=4 片并联组成 4K×32；再做字扩展：16K/4K=4 组。因此芯片总数为 4×4=16 片，字扩展形成 4 组，每次访问由高位地址选择其中一组。
▶下列情形中，最能直接说明两个进程发生死锁的是：操作系统简单
A. P1 正在使用 R1，P2 正在使用 R2，二者都能继续运行
B. P1 持有 R1 并等待 R2，P2 持有 R2 并等待 R1，二者都无法继续
C. P1 等待 I/O 完成，P2 正在使用 CPU
D. P1 和 P2 同时请求同一个可共享的只读文件
答案：B
📖 解析：B 形成循环等待：P1 占有 R1 等待 P2 持有的 R2，P2 占有 R2 等待 P1 持有的 R1，且资源不能被强制剥夺，两个进程都无法推进。这是死锁的典型例子；单纯等待 I/O 或竞争可共享资源不一定构成死锁。
▶关于 ICMP 协议及其典型应用，下列说法正确的是：计算机网络中等
A. ICMP 属于传输层，主要为 TCP 提供可靠字节流
B. ping 通常使用 ICMP 回送请求/回送应答，traceroute 可利用 TTL 超时产生的 ICMP 差错报告
C. ICMP 只用于 IPv6，IPv4 网络中不能使用 ICMP

▶关于距离向量路由算法和链路状态路由算法的比较，下列说法正确的是：计算机网络困难
A. 距离向量算法向所有路由器泛洪完整拓扑，并使用 Dijkstra 算法计算最短路
B. 链路状态算法只向邻居交换到各目的网络的距离，不需要建立拓扑数据库
C. 距离向量算法通常基于 Bellman-Ford 思想与邻居交换距离信息；链路状态算法泛洪链路状态并在本地运行 Dijkstra 算法
D. 两种算法都不会产生计数到无穷问题，因为路由器始终拥有全网拓扑
答案：C
📖 解析：距离向量路由器通常只掌握邻居通告的距离和方向，根据 Bellman-Ford 类递推更新路由，可能出现计数到无穷等收敛问题。链路状态路由器泛洪自身链路状态，形成全网拓扑数据库，再使用 Dijkstra 计算最短路径。因此 C 正确，A、B 混淆了两类算法，D 也错误。

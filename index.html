▶🧩 LeetCode 每日一题：Circle and Rectangle Overlapping中等
给定一个圆的圆心 (xCenter, yCenter) 和半径 radius，以及一个轴对齐矩形的左下角 (x1, y1) 与右上角 (x2, y2)，判断圆与矩形是否有重叠。边界接触也算重叠。
💡 解题思路：把圆心分别限制到矩形的横纵坐标范围内，得到矩形中距离圆心最近的点 (nearestX, nearestY)。圆心到该点的距离就是圆与矩形之间的最短距离；若这个距离不超过半径，二者就重叠。
🔧 题解：对圆心坐标做 clamp：nearestX=min(max(xCenter,x1),x2)，nearestY=min(max(yCenter,y1),y2)。比较 (xCenter-nearestX)^2+(yCenter-nearestY)^2 与 radius^2，使用平方避免开方。时间复杂度 O(1)，空间复杂度 O(1)。
class Solution:
    def checkOverlap(self, radius: int, xCenter: int, yCenter: int,
                     x1: int, y1: int, x2: int, y2: int) -> bool:
        nearest_x = min(max(xCenter, x1), x2)
        nearest_y = min(max(yCenter, y1), y2)
        dx = xCenter - nearest_x
        dy = yCenter - nearest_y
        return dx * dx + dy * dy <= radius * radius

▶采用除留余数法 h(k)=k mod 13，散列表下标为0～12，使用线性探测。将关键字26、39、52、14依次插入后，四个关键字最终所在下标分别是？数据结构简单
A. 26→0，39→1，52→2，14→3
B. 26→0，39→0，52→1，14→2
C. 26→1，39→2，52→3，14→4
D. 26→0，39→1，52→3，14→4
答案：A
📖 解析：四个关键字对13取模都为0。26先放入0；39冲突后探测到1；52继续探测到2；14继续探测到3。因此最终位置为0、1、2、3，选A。此时装填因子为4/13。

A. 前者的操作数就是常数0x1234，后者的操作数是主存地址0x1234处的内容

▶某系统采用段页式存储，32位逻辑地址格式为：高4位段号、接着10位页号、低12位页内偏移。对于逻辑地址0xA5C12345，段号、页号和页内偏移分别是多少？操作系统困难
A. 0xA，0x12，0x345
B. 0xA，0x5C1，0x345
C. 0xA5，0xC1，0x2345
D. 0x5，0xA12，0x345
答案：A
📖 解析：低12位直接得到页内偏移0x345；去掉低12位后，接下来的10位为页号，即(0xA5C12345>>12)&0x3FF=0x12；最高4位为段号0xA。因此三者为0xA、0x12、0x345，选A。

▶🧩 LeetCode 每日一题：Removing Minimum and Maximum From Array中等
给定一个下标从 0 开始、元素互不相同的整数数组 nums。数组中的最小值和最大值必须同时被删除；一次删除只能从数组首端或尾端移除一个元素。请返回删除这两个元素所需的最少操作次数。例如 nums=[2,10,7,5,4,1,8,6] 时，最少删除 5 个元素。
💡 解题思路：先线性扫描找到最小值和最大值的下标，并令 left=min(posMin,posMax)、right=max(posMin,posMax)。删除两者只有三类最优方案：从左端连续删除到 right、从右端连续删除到 left，或分别从两端删除（左端删到 left 且右端删到 right，亦可交换两者的角色）。计算这三类方案的代价并取最小值。
🔧 题解：设数组长度为 n。三种代价分别为 right+1、n-left、(left+1)+(n-right)。其中第三种表示从两端夹取区间 [left,right]，覆盖了两种分配方向中的较优者；也可以显式计算两种混合方案。扫描找极值后即可 O(n) 得到答案，额外空间 O(1)。
from typing import List

class Solution:
    def minimumDeletions(self, nums: List[int]) -> int:
        n = len(nums)
        min_pos = nums.index(min(nums))
        max_pos = nums.index(max(nums))
        left, right = sorted((min_pos, max_pos))

        remove_left = right + 1
        remove_right = n - left
        remove_both = (left + 1) + (n - right)

        return min(remove_left, remove_right, remove_both)

▶Peterson 算法中，P0 和 P1 均已将自己的 flag 置为 true；随后 P0 执行 turn=1，P1 执行 turn=0。此后两者都执行 while 条件检查时，谁能进入临界区？操作系统困难
A. P0 和 P1 都能进入
B. 只有 P0 能进入
C. 只有 P1 能进入
D. 两者都不能进入
答案：B
📖 解析：Peterson 算法中，P0 等待 flag[1] 且 turn==1；P1 等待 flag[0] 且 turn==0。最后一次写入使 turn=0，因此 P0 的等待条件为假，可以进入临界区；P1 的等待条件为真，只能等待 P0 离开并清除 flag[0]。这体现了 turn 变量在双方同时竞争时的仲裁作用。

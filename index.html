▶🧩 LeetCode 每日一题：Valid Parenthesis StringMedium
给定仅由 '('、')' 和 '*' 组成的字符串。星号 '*' 可以解释为左括号、右括号或空字符串；判断该字符串能否变成有效括号字符串。
💡 解题思路：贪心维护当前未匹配左括号数量的可能范围 [low, high]。遇到 '(' 时两端都加一；遇到 ')' 时两端都减一，low 不低于 0；遇到 '*' 时它可以作右括号或左括号，因此 low=max(0,low-1)，high 加一。若 high 变成负数，说明无论如何都缺少左括号；扫描结束时 low 为 0 即存在一种解释使括号全部匹配。
🔧 题解：区间 [low, high] 表示处理当前前缀后可能的未匹配左括号数量。每个字符只更新常数个状态，不需要枚举星号的三种解释。时间复杂度 O(n)，额外空间复杂度 O(1)。
class Solution:
    def checkValidString(self, s: str) -> bool:
        low = high = 0
        for ch in s:
            if ch == '(':
                low += 1
                high += 1
            elif ch == ')':
                low = max(0, low - 1)
                high -= 1
            else:  # '*' 可作为 '('、')' 或空
                low = max(0, low - 1)
                high += 1
            if high < 0:
                return False
        return low == 0

▶对有向图执行 Kahn 入度删除算法，若最终所有顶点都被输出，则可以确定什么？数据结构简单
A. 图中存在有向环
B. 图是有向无环图
C. 图必定连通
D. 每个顶点的入度都相同
答案：B
📖 解析：Kahn 算法反复输出当前入度为 0 的顶点并删除其出边。若仍有顶点却没有入度为 0 的顶点，剩余部分含有有向环；若全部顶点均能输出，则图无环，存在拓扑序。算法不要求图连通。
▶下列事件中，通常属于外部中断源的是哪一项？计算机组成原理简单
A. 算术运算溢出
B. 指令地址越界
C. 外设输入完成并发出中断请求
D. 除数为零
答案：C
📖 解析：外部中断由 CPU 外部的中断源引起，例如 I/O 设备完成操作、时钟中断。溢出、越界和除零均由当前指令执行过程引起，属于内部异常/程序性中断。
▶用户在同一文件系统内为文件 F 建立硬链接 H 和符号链接 S。随后删除目录项 F，哪项描述正确？操作系统中等
A. H 与 S 都必然失效
B. H 仍可访问文件内容，S 通常因目标路径失效而成为悬空链接
C. H 成为悬空链接，S 仍可访问原文件内容
D. 删除 F 会同时删除 H 和 S 指向的全部数据
答案：B
📖 解析：硬链接是同一文件 inode 的另一个目录项，删除一个目录项不会删除其他硬链接；只要链接计数非零，数据仍可访问。符号链接保存目标路径，原路径删除后通常无法解析。硬链接一般不能跨文件系统，也通常不能指向目录。

▶🧩 LeetCode 每日一题：Minimum Moves to Clean the Classroom中等
给定一个 m×n 网格 classroom：S 是起点，L 是必须收集的垃圾，R 是可反复使用且能将能量恢复至满值的充能区，X 是不可通行的障碍，. 是空地。学生初始拥有 energy 点能量，每移动到相邻格消耗 1 点；能量为 0 时只有位于 R 才能继续移动。返回收集全部垃圾所需的最少移动次数；无法完成则返回 -1。
💡 解题思路：把已收集垃圾集合用二进制 mask 表示，状态为（行、列、mask、剩余能量）。从起点做 BFS，每次向四个方向扩展；进入 L 就置对应位，进入 R 就把能量恢复为初始值。BFS 首次到达 mask 全 1 的状态时即得到最少步数。访问标记必须包含剩余能量，因为同一位置和垃圾集合下，不同能量会决定后续可达性。
🔧 题解：先扫描网格记录起点和每个 L 的编号；队列元素为 (r, c, mask, remain, distance)。移动前要求 remain>0，移动后若落在 R 则将 remain 重置为 energy。用集合去重状态，避免重复搜索；最多 10 个垃圾，因此 mask 至多 2^10 种。
from collections import deque
from typing import List

class Solution:
    def minMoves(self, classroom: List[str], energy: int) -> int:
        m, n = len(classroom), len(classroom[0])
        start = None
        litter_id = {}
        for r in range(m):
            for c, ch in enumerate(classroom[r]):
                if ch == 'S':
                    start = (r, c)
                elif ch == 'L':
                    litter_id[(r, c)] = len(litter_id)

        target = (1 << len(litter_id)) - 1
        q = deque([(start[0], start[1], 0, energy, 0)])
        seen = {(start[0], start[1], 0, energy)}
        directions = ((1, 0), (-1, 0), (0, 1), (0, -1))

        while q:
            r, c, mask, remain, dist = q.popleft()
            if mask == target:
                return dist
            if remain == 0:
                continue
            for dr, dc in directions:
                nr, nc = r + dr, c + dc
                if not (0 <= nr < m and 0 <= nc < n):
                    continue
                if classroom[nr][nc] == 'X':
                    continue
                next_remain = remain - 1
                if classroom[nr][nc] == 'R':
                    next_remain = energy
                next_mask = mask
                if (nr, nc) in litter_id:
                    next_mask |= 1 << litter_id[(nr, nc)]
                state = (nr, nc, next_mask, next_remain)
                if state not in seen:
                    seen.add(state)
                    q.append((nr, nc, next_mask, next_remain, dist + 1))
        return -1

▶一棵含 n 个结点的非空二叉树采用二叉链表存储。所有结点共有多少个空指针域？数据结构简单
A. n-1
B. n
C. n+1
D. 2n
答案：C

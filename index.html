▶🧩 LeetCode 每日一题：Maximum Number of Non-overlapping Palindrome Substrings困难
给定字符串 s 和整数 k，求最多能从 s 中选出多少个互不重叠的回文子串，要求每个子串的长度至少为 k。子串必须是连续的一段，选出的子串之间不能共享字符。
💡 解题思路：先识别所有回文子串，再用前缀动态规划选择数量最多且互不重叠的区间。令 dp[i] 表示前 i 个字符（s[0:i]）中最多能选出的回文子串数。扫描回文子串 s[l:r+1] 时，若长度至少为 k，则用 dp[l]+1 更新 dp[r+1]；同时允许跳过当前字符，用 dp[i+1]=max(dp[i+1], dp[i]) 保持最优值。
🔧 题解：用二维状态 pal[l][r] 判断 s[l:r+1] 是否为回文：两端字符相同且内部为空或内部也是回文。按子串长度递增填表，随后按右端点递增进行前缀 DP。每个符合长度要求的回文区间只与其左端之前的最优前缀拼接，因此不会重叠。时间复杂度 O(n²)，空间复杂度 O(n²)。
class Solution:
    def maxPalindromes(self, s: str, k: int) -> int:
        n = len(s)
        pal = [[False] * n for _ in range(n)]
        dp = [0] * (n + 1)

        for length in range(1, n + 1):
            for left in range(n - length + 1):
                right = left + length - 1
                pal[left][right] = (s[left] == s[right] and
                                    (length <= 2 or pal[left + 1][right - 1]))

        for end in range(n):
            dp[end + 1] = dp[end]
            for start in range(end + 1):
                if end - start + 1 >= k and pal[start][end]:
                    dp[end + 1] = max(dp[end + 1], dp[start] + 1)

        return dp[n]

• x^TAx 展开后，a_ii 对应 x_i² 项；当 A 对称时，a_ij 与 a_ji 共同产生 2a_ij x_i x_j。
• 同一个二次型的对称矩阵表示唯一；非对称矩阵的反对称部分对 x^TAx 没有贡献。
• 二次型的秩定义为其矩阵的秩，记为 r(f)=r(A)。

f=x^TAx（A唯一对称）；a_ii=xi²系数，a_ij=交叉项系数一半

C. 虚拟存储器直接增加了机器的物理主存容量

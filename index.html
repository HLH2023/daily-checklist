▶🧩 LeetCode 每日一题：Maximum Length Substring With Two OccurrencesEasy
给你一个字符串 s，请你找出满足「每个字符至多出现两次」的最长子串的长度。示例 1：s = "bcbbbcba"，输出 4，最长满足条件的子串为 "bcba"（b 出现 2 次、c 出现 1 次、a 出现 1 次）。示例 2：s = "aaaa"，输出 2。
💡 解题思路：滑动窗口：用右指针扩展窗口并把新字符计数加 1，一旦某字符出现次数超过 2，就用左指针收缩窗口直到重新满足条件；每次用当前窗口长度更新答案。窗口内始终保持所有字符频次 ≤ 2。
🔧 题解：双指针滑动窗口，一次遍历即可求出全局最长合法子串：窗口合法 ⇔ 每个字符频次 ≤ 2。时间复杂度 O(n)（每个字符至多进出窗口一次），空间复杂度 O(1)（仅需统计 26 个小写字母）。题目规模 n ≤ 50，暴力枚举所有子串 O(n²) 也可行，但滑动窗口是最优写法。
class Solution:
    def maximumLengthSubstring(self, s: str) -> int:
        cnt = {}
        left = ans = 0
        for right, ch in enumerate(s):
            cnt[ch] = cnt.get(ch, 0) + 1
            while cnt[ch] > 2:
                cnt[s[left]] -= 1
                left += 1
            ans = max(ans, right - left + 1)
        return ans

▶📐 高数：极限的性质（唯一性·局部有界性·保号性）高数
若 lim(x→x₀) f(x) = A 存在，则：① A 唯一；② f(x) 在 x₀ 的某去心邻域内有界；③ 若 A>0（或 A<0），则存在去心邻域使 f(x) 与 A 同号
📌 要点：极限刻画的是函数在 x→x₀ 过程中的变化趋势，与 f(x₀) 的值无关（x₀ 处甚至可以没有定义）。三条性质是后续求极限与证明题的基石：唯一性用于反证「极限不存在」；有界性是「有界 × 无穷小 = 无穷小」与夹逼定理的前提；保号性用于由极限符号推断函数局部符号。
• 极限存在必唯一：同一点不可能同时趋于两个不同的值
• 局部有界性：极限存在 ⇒ 在该点某去心邻域内有界（反之不成立）
• 保号性：极限为正 ⇒ 附近函数值也为正，「局部」「去心」不能丢
🧭 套路：看到「极限存在」先想有界，看到「极限为正/负」先想保号；性质只保证去心邻域内的结论。
▶📐 高数：极限的四则运算法则与复合高数
若 lim f(x)=A、lim g(x)=B 均存在，则 lim(f±g)=A±B，lim(f·g)=A·B，lim(f/g)=A/B（B≠0）
📌 要点：四则运算法则的前提是参与运算的各极限都存在（除法还要求分母极限非零），否则不能直接套用。遇到 0/0 型先消去零因子（约分、有理化）；遇到 ∞/∞ 型「抓大头」，分子分母同除最高次幂。复合函数求极限可令 u=g(x) 换元，前提是内外层极限均存在。
• 前提：各极限存在；除法要求分母极限 B≠0
• 0/0 型：约去公因子，如 (x²-1)/(x-1) 化简为 x+1 后再代
• ∞/∞ 型：分子分母同除 x 的最高次幂，抓大头
🧭 套路：能代就代，不能代先化简——0/0 约分或有理化，∞/∞ 抓大头，化简后仍可用四则法则拆开算。
▶📐 线代：行列式的性质（倍加不变·体积解释）线代
① det Aᵀ = det A；② 两行（列）互换，值变号；③ 某行乘 k，值乘 k；④ 两行成比例 ⇒ 值为 0；⑤ 某行加上另一行的 k 倍（倍加），值不变
📌 要点：按定义展开计算量大，利用性质先化简再计算是求行列式的标准套路。倍加变换（rᵢ + k·rⱼ）不改变行列式值，常用于把矩阵化为上三角（或阶梯形）后直接求值。几何上，二阶行列式是平行四边形面积、三阶行列式是平行六面体体积——倍加相当于「剪切」变换，面积与体积都不变。
• 转置值不变；互换两行变号；某行提公因子 k 值乘 k
• 两行相同或成比例 ⇒ det = 0（含某行全 0）
• 倍加 rᵢ + k·rⱼ 值不变——化上三角的利器
🧭 套路：化上三角全程只用倍加操作，值不变；若发现两行成比例或某行全 0，直接得 0，不用算。
▶📐 线代：行列式按行（列）展开定理线代
det A = Σⱼ aᵢⱼ·Aᵢⱼ，其中代数余子式 Aᵢⱼ = (-1)^(i+j)·Mᵢⱼ
📌 要点：余子式 Mᵢⱼ 是划去第 i 行第 j 列后剩下的 n-1 阶行列式，代数余子式 Aᵢⱼ 再乘符号 (-1)^(i+j)（符号按「+−+」棋盘格排列，即 (1,1) 位置为正）。展开定理把 n 阶行列式降为 n-1 阶，是计算与证明的核心工具：选含 0 最多的行（列）展开可大幅减少计算量。
• 代数余子式 Aᵢⱼ = (-1)^(i+j)·Mᵢⱼ，符号正负相间
• 按第 i 行展开：det = aᵢ₁Aᵢ₁ + aᵢ₂Aᵢ₂ + … + aᵢₙAᵢₙ
• 选 0 最多的行或列展开，计算量最小；如 |1 2 3; 0 4 5; 1 0 6| 按第一行展开 = 1×24 − 2×(−5) + 3×(−4) = 22
🧭 套路：先找 0：哪行（列）0 多就按哪行（列）展开；符号按 (1,1) 为 + 的棋盘格判断。

▶设 F(1)=F(2)=1，当 n≥3 时 F(n)=F(n-1)+F(n-2)。若用直接递归算法计算 F(n)，且每次递归调用仅需常数级辅助空间，则该算法的时间复杂度和空间复杂度分别是（　）？数据结构简单
A. O(2ⁿ)、O(n)
B. O(2ⁿ)、O(2ⁿ)
C. O(n²)、O(n)
D. O(n)、O(n)
答案：A
📖 解析：直接递归计算斐波那契会展开成一棵递归二叉树，结点总数约为 2ⁿ 量级，因此时间 O(2ⁿ)。而空间复杂度看的是递归工作栈的最大深度：从 F(n) 一路递归到 F(1)，调用栈最深为 n 层，每层仅常数空间，故空间 O(n)。考点回顾：算法的时间复杂度取决于基本操作执行次数（递归树结点数），空间复杂度取决于递归栈的最大深度，二者不要混淆。
▶某 CPU 主频为 2 GHz，运行某程序时平均 CPI 为 4，则该程序在该 CPU 上的运行速度约为（　）MIPS？计组简单
A. 250
B. 500
C. 1000
D. 2000
答案：B
📖 解析：每秒执行的指令条数 = 主频 / CPI = 2×10⁹ / 4 = 5×10⁸ 条，即 500 MIPS。也可直接套公式 MIPS = f / (CPI×10⁶) = 2000 / 4 = 500。注意 CPI 越大说明每条指令平均耗时越长，速度越慢；且 MIPS 只在同指令集体系下可比，跨体系比较可能失真（可用 MFLOPS 或运行时间补充衡量）。考点回顾：主频、CPI、指令条数与执行时间的关系为 T = 指令数 × CPI / 主频。
▶下列关于系统调用的叙述中，正确的是（　）？OS中等
A. 陷入指令（访管指令）由内核态执行，用于完成系统调用服务
B. 系统调用与库函数完全等价，所有库函数都是系统调用的封装
C. 用户程序通过陷入指令请求操作系统内核服务，执行时 CPU 由用户态切换到内核态
D. 系统调用的参数只能通过寄存器传递，不能存放在内存中
答案：C
📖 解析：A 错：陷入指令本身在用户态执行，它的作用是引起中断、把 CPU 从用户态切换到内核态，真正执行系统调用服务程序的是内核。B 错：部分库函数（如 printf 内部调用 write）确实封装了系统调用，但大量纯计算类库函数（如 strlen、sqrt）不涉及系统调用。C 对：陷入指令是用户程序请求内核服务的唯一途径，执行后特权级由用户态切换为内核态。D 错：系统调用参数可通过寄存器、堆栈或内存块等传递。考点回顾：系统调用 = 陷入指令（用户态执行）+ 内核态服务程序，参数传递方式多样。
▶在 TCP/IP 五层参考模型中，数据链路层的协议数据单元（PDU）是（　）？网络简单
A. 报文（message）
B. 报文段（segment）
C. 数据报（packet）
D. 帧（frame）
答案：D
📖 解析：各层 PDU 名称：应用层为报文（message），传输层为报文段（segment），网络层为数据报/分组（packet），数据链路层为帧（frame），物理层为比特流。发送端自上而下逐层封装（每层加首部），接收端自下而上逐层解封装，这正是数据封装与解封装的过程。注意传输层的 PDU 在 TCP 中叫报文段、在 UDP 中叫用户数据报，不要与网络层的 IP 数据报混淆。
▶下列关于网络协议三要素的叙述中，正确的是（　）？网络困难
A. 语法规定通信双方应完成的操作与应作出的响应
B. 语义规定数据与控制信息的结构或格式
C. 同步（时序）详细说明事件实现顺序的规则
D. 三要素中语义最为核心，其余要素可以省略
答案：C
📖 解析：协议三要素：语法——数据与控制信息的结构或格式；语义——发出何种控制信息、完成何种动作以及作出何种应答；同步（时序）——事件实现顺序的详细说明。A 错：把语法与语义说反了，规定「做什么」的是语义而非语法。B 错：把语义与语法说反了，规定「格式」的是语法而非语义。D 错：三要素缺一不可、没有主次之分，同步（时序）恰恰是协议区别于一般约定的关键所在。考点回顾：记忆口诀「语法看格式、语义看动作、同步看顺序」。

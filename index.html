▶🧩 LeetCode 每日一题：Maximum Length Substring With Two OccurrencesEasy
给你一个字符串 s，请找出满足「每个字符至多出现两次」的最长子串的长度。示例 1：s = "bcbbbcba"，最长合法子串为 "bcba"（b 出现 2 次、c 出现 1 次、a 出现 1 次），答案为 4。示例 2：s = "aaaa"，每个字符至多出现 2 次，答案为 2。
💡 解题思路：滑动窗口（双指针）：右指针逐个加入字符并计数，一旦某字符频次超过 2，就左移左指针并减少对应计数，直到窗口重新合法；每次用 right − left + 1 更新答案。窗口内任意时刻所有字符频次 ≤ 2。
🔧 题解：一次遍历 O(n)：每个字符最多进、出窗口各一次；只需统计 26 个小写字母，计数数组/字典空间 O(1)。本题 n ≤ 50，暴力枚举所有子串 O(n²) 也可行，但滑动窗口是经典双指针模板写法，务必掌握。
class Solution:
    def maximumLengthSubstring(self, s: str) -> int:
        cnt = {}
        left = ans = 0
        for right, ch in enumerate(s):
            cnt[ch] = cnt.get(ch, 0) + 1
            while cnt[ch] > 2:
                cnt[s[left]] -= 1
                left += 1
            ans = max(ans, right - left + 1)
        return ans

📌 要点：核心是量词顺序「先 ε 后 N」：ε 任意小刻画逼近程度，N = N(ε) 刻画『足够远』，ε 越小 N 通常越大。数列极限只与后面无穷多项有关，改变或删去前有限项不影响极限。
• ε 的任意性：必须对任意 ε>0 都成立，ε 越小要求越高
• N 的存在性：N 一般依赖 ε，记作 N(ε)，只要求存在、不要求最小
• 收敛数列必有界，且极限唯一（有界是收敛的必要条件，非充分）

▶📐 高数·第1天·极限：函数极限 ε-δ 定义D1
lim(x→x₀) f(x) = A ⟺ ∀ε>0，∃δ>0，当 0<|x − x₀|<δ 时恒有 |f(x) − A| < ε
📌 要点：δ 是 x₀ 的去心邻域半径，条件 0<|x−x₀| 强调 x≠x₀：极限与 f(x₀) 是否有定义、取何值无关（如 (x²−1)/(x−1) 在 x=1 处无定义，但极限为 2）。δ 一般依赖 ε，也随 x₀ 变化。
• 去心邻域：0<|x−x₀|<δ，极限与 f(x₀) 无关
• δ=δ(ε)：δ 随 ε 变小而变小，证明时先放缩再取 δ
• 单侧极限：左、右极限存在且相等 ⟺ 极限存在

▶📐 线代·行列式与矩阵：余子式与代数余子式行列式与矩阵
M_ij 为余子式；A_ij = (−1)^(i+j)·M_ij；|A| = Σ a_ij·A_ij（按第 i 行展开）
📌 要点：余子式 M_ij：划去第 i 行、第 j 列后剩下的 n−1 阶行列式；代数余子式 A_ij = (−1)^(i+j)·M_ij。按行（列）展开定理：|A| 等于任一行（列）的元素与其对应代数余子式乘积之和，这是高阶行列式降阶计算的核心工具。
• 符号规律：符号 (−1)^(i+j) 呈棋盘状交替，主对角线方向为 + − +
• 展开定理：任选一行（列）展开均相等，选 0 最多的行（列）计算量最小
• 异乘变零：第 i 行元素与第 j 行（i≠j）对应代数余子式乘积之和 = 0
默写核心结论：＿＿＿
A_ij = (−1)^(i+j)·M_ij；|A| = Σ a_ij·A_ij
🧭 套路：高阶行列式先做行（列）变换化出 0，再按 0 最多的行（列）展开降阶，直到化成三角行列式或二阶。
▶📐 线代·行列式与矩阵：初等矩阵行列式与矩阵
E(i,j)、E(i(k))、E(ij(k))；|E(i,j)| = −1，|E(i(k))| = k，|E(ij(k))| = 1
📌 要点：初等矩阵 = 单位阵 E 经一次初等变换所得：E(i,j) 交换 i、j 两行（列）；E(i(k)) 第 i 行乘非零常数 k；E(ij(k)) 把第 j 行（列）的 k 倍加到第 i 行（列）。左乘作行变换、右乘作列变换；初等矩阵均可逆，逆仍为同类型初等矩阵。
• 左乘行变、右乘列变：E·A 相当于对 A 做相应行变换，A·E 做列变换
• 行列式：|E(i,j)| = −1、|E(i(k))| = k、|E(ij(k))| = 1（初等矩阵均可逆 ⟹ 行列式 ≠ 0）
• 逆矩阵：E(i,j)⁻¹ = E(i,j)，E(i(k))⁻¹ = E(i(1/k))，E(ij(k))⁻¹ = E(ij(−k))
默写核心结论：＿＿＿
E(i,j)、E(i(k))、E(ij(k))；|E(i,j)| = −1，|E(i(k))| = k，|E(ij(k))| = 1
🧭 套路：快速判断：先看是否由单位阵一次初等变换得到；做题时先确定是行变换还是列变换（左乘/右乘），再套行列式结论。

▶在一个长度为 100 的顺序表中插入一个新元素，若插入位置（含表尾共 101 个位置）等概率，则平均需要移动的元素个数是（　）。数据结构简单
A. 49
B. 50
C. 51
D. 99
答案：B
📖 解析：在第 i 个位置（1≤i≤n+1）插入需移动 n−i+1 个元素，等概率时平均移动次数 = (n + (n−1) + … + 0) / (n+1) = n/2 = 50。注意插入有 n+1 个可能位置，所以平均是 n/2 而不是 (n+1)/2；对比删除操作：删除有 n 个可能位置，平均移动 (n−1)/2 个。两者时间复杂度都是 O(n)，这正是顺序表插入删除低效的根源（随机存取、物理连续）。
▶某程序的串行部分占 40%，其余 60% 可并行执行。若将并行部分加速到原来的 4 倍，则整个程序的加速比约为（　）。计算机组成原理简单
A. 1.56
B. 1.82
C. 2.17
D. 2.50
答案：B
📖 解析：Amdahl 定律：S = 1 / ((1−f) + f/k)，其中 f = 0.6 为可加速部分占比，k = 4 为该部分加速倍数，1−f = 0.4 为不可加速部分。代入得 S = 1 / (0.4 + 0.6/4) = 1 / 0.55 ≈ 1.82。关键结论：即使并行部分无限加速（k→∞），加速比也至多趋近 1/(1−f) = 2.5——串行部分占比是性能瓶颈，这就是 Amdahl 定律的核心思想。
▶下列关于进程的叙述中，正确的是（　）。操作系统中等
A. 进程是程序的一次执行过程，一个程序只能对应一个进程
B. 进程具有动态性、并发性、独立性、异步性，其中并发性指进程按各自独立的、不可预知的速度向前推进
C. 进程是资源分配的基本单位，线程是 CPU 调度的基本单位，同一进程内的线程共享该进程的资源
D. 进程与程序都是动态的概念，二者的区别仅在于进程分配了内存而程序没有
答案：C
📖 解析：A 错：一个程序可对应多个进程（如多用户同时运行同一程序，各有一个进程）。B 错：把两个特征的定义说反了——并发性指多个进程同存于内存中、在一段时间内交替运行；异步性才指进程按各自独立的、不可预知的速度向前推进。C 对：引入线程后，进程是资源分配的基本单位，线程是调度的基本单位，同一进程的线程共享地址空间与资源。D 错：程序是静态的（指令序列），进程是动态的（程序的一次执行），且进程拥有 PCB 等结构，区别远不止内存分配。
▶下列关于编码与调制的叙述中，正确的是（　）。计算机网络简单
A. 曼彻斯特编码在每个码元中间发生电平跳变，该跳变兼作时钟与数据信号，因此还需要额外的同步时钟线
B. 差分曼彻斯特编码在每个码元开始处有跳变表示 0、无跳变表示 1，中间跳变仅作时钟，抗干扰能力较强
C. 调制是把数字信号转换成数字信号的过程，编码是把模拟信号转换成数字信号的过程
D. 4B/5B 编码是曼彻斯特编码的改进，编码效率为 50%
答案：B
📖 解析：A 错：曼彻斯特编码的中间跳变既作时钟又作数据，自含时钟，无需额外时钟线。B 对：差分曼彻斯特编码看码元开始处有无跳变来区分 0/1（有跳变表示 0、无跳变表示 1），中间跳变只作时钟，抗干扰能力强，常用于令牌环网。C 错：概念颠倒——编码是数字→数字（NRZ、曼彻斯特、4B/5B），调制是数字→模拟（ASK、FSK、PSK）。D 错：4B/5B 用 5 位码组表示 4 位数据，效率 80%，它改进的是曼彻斯特编码效率只有 50% 的缺点。
▶某信道带宽为 3000 Hz，信噪比为 30 dB。根据香农定理，该信道能达到的最大无差错数据传输率约为（　）。（log2 1001 ≈ 9.97）计算机网络困难
A. 9.97 kbps
B. 29.9 kbps
C. 30.9 kbps
D. 90 kbps
答案：B
📖 解析：先做 dB 换算：信噪比 30 dB ⟹ S/N = 10^(30/10) = 1000。香农公式 C = W·log2(1 + S/N) = 3000 × log2(1001) ≈ 3000 × 9.97 ≈ 29.9 kbps。两个易错点：① 题目给的是 dB 值必须换算成倍数，很多同学直接代入 30 或漏换算；② 香农公式给出的是有噪声信道无差错传输的极限速率（与奈奎斯特定理对比：奈奎斯特给的是无噪声下极限码元速率 2W，且与进制数 M 有关：2W·log2 M）。本题若直接用 10 代替 log2 1001 得 30 kbps 属近似，精确值约 29.9 kbps。

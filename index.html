▶🧩 LeetCode 每日一题：Reverse Substrings Between Each Pair of ParenthesesMedium
给定一个由小写英文字母和圆括号组成、括号配对正确的字符串 s。每次遇到一对括号，就反转它们之间的子串；括号可以嵌套。最终返回去掉所有括号后的字符串。例如：s = "(u(love)i)"，结果为 "iloveu"。
💡 解题思路：先用栈配对每个左右括号的下标。随后从左向右扫描字符串；遇到括号就跳到与之配对的位置并反转行进方向，普通字符则加入结果。这样无需真的反转子串，也能正确处理嵌套。
🔧 题解：配对预处理和最终遍历都各访问每个字符常数次，时间复杂度 O(n)，空间复杂度 O(n)。扫描方向翻转等价于逐层执行括号内反转，遍历结束时括号本身不会加入答案。
class Solution:
    def reverseParentheses(self, s: str) -> str:
        n = len(s)
        pair = [0] * n
        stack = []
        for i, ch in enumerate(s):
            if ch == '(':
                stack.append(i)
            elif ch == ')':
                j = stack.pop()
                pair[i] = j
                pair[j] = i

        ans = []
        i, direction = 0, 1
        while 0 <= i < n:
            if s[i] == '(' or s[i] == ')':
                i = pair[i]
                direction = -direction
            else:
                ans.append(s[i])
            i += direction
        return ''.join(ans)

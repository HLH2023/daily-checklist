▶🧩 LeetCode 每日一题：Longest Subsequence With Non-Zero Bitwise XOR中等
给定整数数组 nums，求最长的子序列，使该子序列所有元素的按位异或（XOR）结果不为 0。返回该最长长度；若不存在则为 0。
💡 解题思路：若整个数组异或和不为 0，答案为 n；否则去掉任意一个元素（其值不为 0 时）即可使异或非零，答案为 n-1；若全部元素为 0 则答案为 0。
🔧 题解：先求全数组异或和 x：x≠0 → 返回 n；x=0 → 若存在非零元素，删掉它使异或和变为该元素值（非零），返回 n-1；否则全 0 返回 0。
class Solution:
    def longestSubsequence(self, nums: List[int]) -> int:
        x = 0
        for v in nums:
            x ^= v
        if x:
            return len(nums)
        if any(v for v in nums):
            return len(nums) - 1
        return 0

▶某信道带宽为 3000Hz，信噪比 30dB，按香农公式计算最大数据传输率约为（ ） A. 30kbps B. 3000bps C. 30000bps D. 90kbps计算机网络困难

C. 30000bps

答案：C

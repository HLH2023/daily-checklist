▶🧩 LeetCode 每日一题：Sum GameMedium
Alice 和 Bob 轮流把字符串 num 中的 ? 替换为 0 到 9 的任意数字，Alice 先手。字符串长度为偶数；游戏结束后，若前半段数字和等于后半段，Bob 获胜，否则 Alice 获胜。双方都采取最优策略，判断 Alice 是否获胜。
💡 解题思路：只需比较两半当前数字和的差值，以及两半问号数量的差值。设 diff=左半和−右半和，qdiff=左半问号数−右半问号数。若 qdiff=0，则没有可由某一方改变的净问号位置，Alice 只有在 diff 不为 0 时获胜；若 qdiff 不为 0，后手可以通过在问号较多的一侧进行补偿。每次一方填写一个数字，另一方可以在另一侧用 0 到 9 的范围抵消；当问号数量差为奇数时，先手能够制造无法相等的差距。等价判定为：当 qdiff==0 时答案是 diff!=0；否则答案取决于 diff 与 9*qdiff/2 的关系，使用整数形式比较 2*abs(diff) 与 9*abs(qdiff)。
🔧 题解：统计左右两半的数字和与问号数。若两侧问号数相同，直接判断两半数字和是否相等；否则令 diff 为数字和之差、qdiff 为问号数之差。交换左右两半可令 qdiff>0。若 qdiff 为奇数，Alice 必胜；若 qdiff 为偶数，当 abs(diff) != 9*qdiff/2 时 Alice 必胜，否则 Bob 必胜。时间复杂度 O(n)，额外空间复杂度 O(1)。
class Solution:
    def sumGame(self, num: str) -> bool:
        half = len(num) // 2
        diff = 0
        qdiff = 0

        for i, ch in enumerate(num):
            sign = 1 if i < half else -1
            if ch == '?':
                qdiff += sign
            else:
                diff += sign * int(ch)

        if qdiff == 0:
            return diff != 0

        if qdiff < 0:
            qdiff = -qdiff
            diff = -diff

        if qdiff % 2 == 1:
            return True
        return abs(diff) * 2 != 9 * qdiff

A. 队空条件为 front == rear，队满条件为 (rear + 1) % MaxSize == front
B. 队空条件为 (rear + 1) % MaxSize == front，队满条件为 front == rear
C. 入队时 front 加 1，出队时 rear 加 1
D. 该约定下循环队列最多可以存放 MaxSize 个元素
答案：A

▶采用 4 bit 序号字段的滑动窗口协议，在不考虑其他限制时，为避免新旧帧序号混淆，后退 N 帧（GBN）和选择重传（SR）的发送窗口最大值分别为（ ）计算机网络中等
A. GBN 为 8，SR 为 8
B. GBN 为 15，SR 为 8
C. GBN 为 16，SR 为 8
D. GBN 为 15，SR 为 15
答案：B
📖 解析：4 bit 序号的序号空间大小 N=2⁴=16。GBN 接收窗口为1，发送窗口最大为 N−1=15；SR 的发送窗口和接收窗口都不能超过序号空间的一半，最大为 N/2=8，否则无法区分迟到的旧帧和当前窗口内的新帧。

A. 信道划分方法让所有站点共享同一时间、频率和码资源，因此不存在资源划分开销
B. 随机访问方法中站点可以自主决定发送，但发生冲突后通常需要重传或退避
C. 轮询方法由各站点竞争获得令牌，无法从根本上避免多个站点同时发送
D. CSMA/CD 适用于无线局域网，因为无线站点可以在发送时可靠检测碰撞
答案：B

▶🧩 LeetCode 每日一题：Remove Outermost ParenthesesEasy
给定一个由括号组成的有效字符串 s。将其分解为原语（不能再拆成两个非空有效括号串的部分），删除每个原语最外层的一对括号，并按原顺序拼接后返回。
💡 解题思路：从左到右扫描并维护当前括号深度。遇到左括号时，若当前深度大于 0，说明它不是当前原语的最外层括号，先保留，再增加深度；遇到右括号时先减少深度，若减少后仍大于 0，则保留。这样每个原语的首尾外层括号都会被跳过。
🔧 题解：有效字符串保证括号匹配。扫描时，左括号在 depth==0 时是原语的外层起始括号，不加入答案；其余左括号加入答案后 depth 加一。右括号先让 depth 减一；若新的 depth>0，则它不是原语的外层结束括号，加入答案。时间复杂度 O(n)，额外空间复杂度 O(n)（不计输出）。
class Solution:
    def removeOuterParentheses(self, s: str) -> str:
        depth = 0
        result = []

        for ch in s:
            if ch == '(':
                if depth > 0:
                    result.append(ch)
                depth += 1
            else:  # ch == ')'
                depth -= 1
                if depth > 0:
                    result.append(ch)

        return ''.join(result)

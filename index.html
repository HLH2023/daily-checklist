▶🧩 LeetCode 每日一题：Stone Game IXMedium
Alice 和 Bob 继续玩石子游戏。有一行 n 个石子，每个石子有一个值 stones[i]。Alice 先手，两人轮流操作，每回合可移除任意一个石子。若某玩家移除石子后，所有已移除石子值之和能被 3 整除，则该玩家输。若石子全部取完（即使轮到 Alice 操作），Bob 自动获胜。双方均最优操作，返回 Alice 能否获胜。
💡 解题思路：游戏只与已取石子的和模 3 的余数有关，与具体数值无关。统计余数为 0、1、2 的石子个数 cnt0、cnt1、cnt2：取余数 0 的石子不改变当前和的余数，只是把回合权让给对方（奇数个 0 时先手可加以利用）；取余数 1 的石子后，对方若取余数 2 的石子会使和成为 3 的倍数而输，只能取余数 1（或 0），取余数 2 对称。据此分 cnt0 奇偶两类讨论：cnt0 为偶数时可忽略 0 石子（取 0 等于白送先手权）；cnt0 为奇数时先手可先取一个 0 石子，把麻烦局面抛给对方。
🔧 题解：结论：① cnt0 为偶数时，Alice 必胜 ⟺ cnt1≥1 且 cnt2≥1（Alice 先取 1，Bob 只能跟着取 1 或取 0，双方被迫沿 1↔2 交替消耗，先耗尽的一类恰好轮到 Bob 头上导致其输；若某类为 0，Alice 首步就把和固定住，最终被迫取异类石子而输）；② cnt0 为奇数时，Alice 先取一个 0 石子，等效于 Bob 面对偶数个 0 先手，此时 Alice 必胜 ⟺ |cnt1−cnt2|≥3。时间复杂度 O(n)，空间 O(1)。
class Solution:
    def stoneGameIX(self, stones: List[int]) -> bool:
        cnt = [0, 0, 0]
        for s in stones:
            cnt[s % 3] += 1
        c0, c1, c2 = cnt
        if c0 % 2 == 0:
            return c1 > 0 and c2 > 0
        return abs(c1 - c2) >= 3

▶在带头结点的双链表 L 中，已知指针 p 指向某个结点，现要在 p 之后插入新结点 s，下列操作顺序正确的是（ ）数据结构简单
A. s->next=p->next; p->next->prior=s; s->prior=p; p->next=s
B. p->next=s; s->prior=p; s->next=p->next; p->next->prior=s
C. s->prior=p; p->next=s; s->next=p->next; p->next->prior=s
D. s->next=p->next; s->prior=p; p->next=s; p->next->prior=s
答案：A
📖 解析：双链表插入的关键：先让新结点 s 与 p 的原后继建立双向链接，再修改 p 的指针，避免丢失 p->next。正确顺序为：① s->next=p->next（s 指向后继）；② p->next->prior=s（原后继的前驱改为 s）；③ s->prior=p（s 的前驱指向 p）；④ p->next=s（p 的后继改为 s）。若先执行 p->next=s（选项 B/C/D 的写法），p 的原后继将丢失，无法完成双向连接。
▶设机器字长为 8 位（含 1 位符号位），采用原码表示，下列说法错误的是（ ）计算机组成原理简单
A. +0 的原码为 0000 0000，-0 的原码为 1000 0000
B. 原码中 0 有两种表示，故 8 位原码只能表示 255 个不同的数值
C. 原码可表示的真值范围为 -127 ~ +127
D. 原码表示中，符号位参与数值运算
答案：D
📖 解析：原码的符号位不参与数值运算，数值运算需转为补码进行（或单独处理符号位），故 D 错误。A 正确：0 的原码有两种（+0=0000 0000、-0=1000 0000）；B 正确：因 0 占两种编码，8 位原码实际表示 2^8−1=255 个不同数值；C 正确：8 位原码真值范围 −(2^7−1)~+(2^7−1) 即 −127~+127。
▶关于进程状态转换，下列叙述中错误的是（ ）操作系统中等
A. 就绪→运行：进程被调度程序选中，获得 CPU
B. 运行→阻塞：进程因等待某事件（如 I/O 完成）而主动让出 CPU
C. 阻塞→就绪：进程等待的事件发生，由系统将其唤醒
D. 就绪→阻塞：进程因时间片用完而进入阻塞状态
答案：D

B. A 发 1，B 发 1，C 发 0，D 未发送

答案：A

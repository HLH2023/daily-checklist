▶🧩 LeetCode 每日一题：Maximum Score of Non-overlapping IntervalsHard
给定 intervals[i] = [左端点, 右端点, 权重]，最多选择 4 个互不重叠的区间，使权重总和最大，并返回达到最大总分时字典序最小的原下标数组。两个区间只要共享端点也算重叠。
💡 解题思路：按右端点升序排序。对每个区间，用二分查找找到所有右端点严格小于当前左端点的前驱区间；再用 dp[k][i] 表示在排序后前 i 个区间中恰选 k 个时的最优结果，在跳过当前区间和选择当前区间之间取总权重更大者。最后在 0 到 4 个区间中选择总分最大、下标数组字典序最小的方案。
🔧 题解：排序后令 j=bisect_left(rights, left, 0, i)，这样前驱区间满足 right < left，符合共享边界也重叠的题意。状态转移为 dp[k][i]=max(dp[k][i-1], weight+dp[k-1][j])；同分同数量时比较按原下标升序排列的元组，保留字典序更小者。时间复杂度 O(4n log n)，空间复杂度 O(4n)。
from bisect import bisect_left
from typing import List, Optional, Tuple

class Solution:
    def maximumWeight(self, intervals: List[List[int]]) -> List[int]:
        items = sorted((l, r, w, idx) for idx, (l, r, w) in enumerate(intervals))
        n = len(items)
        rights = [item[1] for item in items]
        # dp[k][i] = (score, original-index tuple), using first i sorted intervals
        dp: List[List[Optional[Tuple[int, Tuple[int, ...]]]]] = [
            [None] * (n + 1) for _ in range(5)
        ]
        for i in range(n + 1):
            dp[0][i] = (0, ())

        def better(a, b):
            if a is None:
                return b
            if b is None:
                return a
            if a[0] != b[0]:
                return a if a[0] > b[0] else b
            return a if a[1] < b[1] else b

        for i, (left, right, weight, original) in enumerate(items, 1):
            for k in range(1, min(4, i) + 1):
                best = dp[k][i - 1]
                j = bisect_left(rights, left, 0, i - 1)
                prev = dp[k - 1][j]
                if prev is not None:
                    candidate = (prev[0] + weight, tuple(sorted(prev[1] + (original,))))
                    best = better(best, candidate)
                dp[k][i] = best

        best = None
        for k in range(5):
            best = better(best, dp[k][n])
        return list(best[1])

▶📐 线代·特征值与特征向量：正交矩阵线代·特征值与特征向量

📌 要点：列(行)向量组为正交单位向量组；|A|=±1；A^{-1}、AB仍正交；性质：正交变换保长度内积
• 正交矩阵的列向量组和行向量组都是正交单位向量组。

▶📐 线代·特征值与特征向量：特征值与特征向量定义线代·特征值与特征向量

📌 要点：特征方程|λE-A|=0；特征向量=齐次方程(λE-A)x=0的非零解；特征子空间维数=n-r(λE-A)
• 若存在非零向量 α 使 Aα=λα，则 λ 是 A 的特征值，α 是属于 λ 的特征向量。

• 求出 λ 后解齐次方程 (λE−A)x=0，所有非零解构成对应特征子空间中的特征向量。

🧭 套路：先求特征方程再逐个代入求特征向量；特征向量必须是非零解，同一特征值对应的特征向量可以有无穷多个。

▶空二叉排序树依次插入关键字 50、30、70、20、40、60、80。成功查找关键字 60 时，依次比较的结点关键字为 50、70、60，共需比较多少次？数据结构简单
A. 2 次
B. 3 次
C. 4 次
D. 5 次
答案：B
📖 解析：插入后根结点为 50，60 大于 50 转向右子树；在结点 70 处因 60 小于 70 转向左孩子 60，第三次比较成功。因此共比较 3 次。
▶某机按字节编址，主存地址为 32 位，Cache 容量为 32KB，块大小为 64B，采用 2 路组相联映射。忽略有效位和脏位，主存地址中的标记字段应占多少位？计算机组成原理简单
A. 16 位
B. 18 位
C. 20 位
D. 22 位
答案：B
📖 解析：块大小 64B=2^6B，块内地址占 6 位。Cache 行数为 32KB/64B=512 行，2 路组相联后组数为 256=2^8，组号占 8 位。因此标记位数为 32−6−8=18 位。

▶移动主机 M 的永久家乡地址为 H。M 离开家乡网络后接入外地网络，家乡代理 HA 和外地代理 FA 均正常工作。通信对端仍向 H 发送分组时，以下处理正确的是：计算机网络中等
A. HA 直接把分组广播到整个互联网，M 自行筛选
B. HA 截获发往 H 的分组，并通过隧道封装后发送给 FA，再由 FA 交付给 M
C. FA 修改通信对端的地址，使其改为 M 的永久家乡地址 H
D. M 必须更换永久地址，否则网络层无法继续通信
答案：B
📖 解析：移动 IP 中，移动节点保留永久家乡地址 H。家乡代理截获发往 H 的分组，通过隧道将其封装并发送到外地代理，外地代理再解封装并交付给移动节点；通信对端无需知道移动节点当前所在网络。
▶空二叉排序树依次插入 50、30、70、20、40、60、80、65、75。删除根结点 50，并采用其中序后继替代法。删除并调整完成后，以下说法正确的是：数据结构困难
A. 新根为 40，且中序序列不再有序
B. 新根为 60，结点 65 仍是 70 的左子树中的结点
C. 新根为 65，结点 60 被直接丢弃
D. 新根仍为 50，只需删除其左孩子
答案：B
📖 解析：根 50 有左右两个孩子，采用中序后继时选择右子树中的最小结点 60 替代 50，再从原位置删除 60。原 60 的右子树为 65，因此 65 接到 70 的左侧；新根为 60，中序序列仍保持有序。

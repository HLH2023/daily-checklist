▶🧩 LeetCode 每日一题：Score of ParenthesesMedium
给定一个平衡括号字符串 s，求其分数。规则：() 的分数为 1；相邻平衡串 AB 的分数为 A+B；包裹平衡串 (A) 的分数为 2×A。
💡 解题思路：从左到右扫描并维护当前嵌套深度 depth。遇到左括号就增加深度；遇到右括号先将深度减一，若它与紧邻的左括号组成 ()，就把 2^depth 加入答案。因为这一对括号的贡献按其外层嵌套层数翻倍，直接累计即可。
🔧 题解：扫描一次即可完成计算。相邻括号段的分数自然累加；每个原子括号对 () 在其外层每多包一层，贡献就乘 2。时间复杂度 O(n)，额外空间复杂度 O(1)。
class Solution:
    def scoreOfParentheses(self, s: str) -> int:
        score = 0
        depth = 0
        for i, ch in enumerate(s):
            if ch == '(':
                depth += 1
            else:
                depth -= 1
                if s[i - 1] == '(':  # 找到原子括号对 ()
                    score += 1 << depth
        return score

▶表达式为 (a+b)×(a+b)，将表达式表示为有向无环图（DAG）而不是普通表达式树时，最主要的优势是什么？数据结构简单
A. 可以消除表达式中的所有运算符
B. 相同的子表达式 (a+b) 可以共享同一个结点，避免重复表示或计算
C. DAG 一定只有唯一的拓扑序列
D. DAG 能表示有向环而表达式树不能
答案：B
📖 解析：DAG 允许多个后继边共享同一子表达式结点，因此 (a+b) 可以只表示一次；普通树会把两处子表达式重复展开。DAG 仍无有向环，但拓扑序不一定唯一。
▶CPU 在执行完当前指令后响应一个可屏蔽外部中断。下列过程顺序最合理的是哪一项？计算机组成原理中等
A. 立即执行中断服务程序 → 保存断点 → 关中断
B. 关中断（或屏蔽同级中断）→ 保存断点等必要现场 → 转入中断服务程序
C. 保存断点 → 恢复现场 → 判断是否有中断请求
D. 清除所有设备请求 → 执行当前指令 → 保存断点

📖 解析：CPU 通常在指令边界检测并响应可屏蔽中断。为避免响应过程中被同级中断打断，先关中断或设置屏蔽，再保存返回所需的断点等现场信息，随后转入相应中断服务程序；具体现场保存范围由硬件和软件约定。

B. 只有磁盘可以打断键盘服务程序，因为磁盘优先级高于键盘
C. 定时器可嵌套打断键盘服务程序；磁盘请求暂不响应，待更高优先级服务完成后再按规则处理
